## How this list was made

- **Rust crates**: generated by `cargo deny --manifest-path src-tauri/Cargo.toml --exclude-dev --target <target> list`
  (the app's crate graph including build-time crates, without dev-dependencies). A crate under a
  choice of licenses (`MIT OR Apache-2.0`) is counted once per license.

  | license                        | Linux x86_64 (286 crates)                                                    | macOS aarch64 (244 crates) |
  | ------------------------------ | ---------------------------------------------------------------------------- | -------------------------- |
  | MIT                            | 254                                                                          | 213                        |
  | Apache-2.0                     | 164                                                                          | 155                        |
  | Apache-2.0 WITH LLVM-exception | 1 (`target-lexicon`, build-time)                                             | 0                          |
  | Unicode-3.0                    | 19                                                                           | 19                         |
  | Zlib                           | 5                                                                            | 11                         |
  | MPL-2.0                        | 5 (`cssparser`, `cssparser-macros`, `dtoa-short`, `option-ext`, `selectors`) | 5 (same)                   |
  | Unlicense                      | 5 (`aho-corasick`, `byteorder`, `memchr`, `same-file`, `walkdir`)            | 5 (same)                   |
  | BSD-3-Clause                   | 4 (`alloc-no-stdlib`, `alloc-stdlib`, `brotli`, `brotli-decompressor`)       | 4 (same)                   |
  | BSD-2-Clause                   | 1 (`Inflector`)                                                              | 1 (same)                   |
  | 0BSD                           | 1 (`adler2`)                                                                 | 1 (same)                   |
  | CC0-1.0, MIT-0                 | 1 (`dunce`)                                                                  | 1 (same)                   |

  The MPL-2.0 crates are used unmodified; their source is on [crates.io](https://crates.io).
  Each crate's license text ships in its source package.

- **JavaScript packages**: generated by `pnpm -C frontend licenses list --prod` (81 packages: MIT 76,
  OFL-1.1 1, Apache-2.0 OR MIT 1, BSD-2-Clause 1, BSD-3-Clause 1, ISC 1). The list includes Vue's
  compiler packages, which the build uses but the app does not carry.
- **Icons**: hand-checked. Lucide and vscode-icons are build-time packages (`@iconify-json/*`); the
  build copies the SVGs the app uses into its code, so `--prod` does not list them. License and
  holder come from each package's `info.json`.
- **System libraries in the AppImage**: hand-checked. The Linux AppImage carries the GTK and
  WebKitGTK libraries of the build machine (LGPL-2.1-or-later and BSD-style licenses; source from
  [webkitgtk.org](https://webkitgtk.org) and [gtk.org](https://www.gtk.org)). The `.deb` and the
  macOS app use the system's copies instead.
