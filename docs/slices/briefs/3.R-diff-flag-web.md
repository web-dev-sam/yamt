`--raw-case` stop working, no alias. The contract with row 1a is only the flag text `--diff` the helper passes to the

## Contract

The helper passes `--diff` to the binary for a compare start. `CompareSource`, `createFixtureCompareSource(log,
search)` and every other export keep their signatures.

## Change

1. `main.ts` and `fixtureCompare.ts` read `diff` from the search (`?diff`, `?diff=<case>`); tests follow, still proving
   the same rules (bare `?diff` and `?diff=` → one empty Compare 1, an unknown case fails naming the known ones, …).
2. app-session: `start-app --diff` (the `Opening` kind and its error text say `diff`), passes `["--diff"]`;
   `start-fixture --diff` / `--diff-case <case>` give `?diff` / `?diff=<case>`; the usage text; tests follow.
3. Both AGENTS.md: `yamt --diff`, `?diff`, `?diff=<case>`.
