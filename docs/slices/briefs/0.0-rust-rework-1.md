   keep the clippy disallowed lists as they are); (c) fail if the `too-many-lines-threshold` lines of the root and
   merge-core `clippy.toml` differ (vision 2 — duplication enforced, not remembered).

   package scripts (`frontend lint`, `frontend typecheck`, `frontend test`, `frontend sfc-order`, `frontend fmt:check`)

5. `deny.toml`: one CP1 comment line on `unmaintained = "all"` stating that cargo-deny v2 config sets scope only and
   `just deny` lowers severity with `--warn unmaintained`.
