# Slice 2.0 — rework 1: the app starts on NVIDIA by itself, one session root, review shoulds

Round 1 (`08ff250`, `V0DesktopShell`) passed both reviews with `should` findings, and its smoke found
that **the app aborts at start on the owner's NVIDIA/Wayland machine** unless
`WEBKIT_DISABLE_DMABUF_RENDERER=1` is set (`Gdk-Message: Error 71 (Protocol error) dispatching to
Wayland display`, no window). The owner decided (plan §2 #43): the app sets that variable itself,
with the project's one `unsafe` line. This round adds that guard, replaces the temporary second git
discovery with a session accessor, and fixes the review findings below. The original brief
`docs/slices/briefs/2.0-desktop-shell.md` still holds for everything not changed here.

## Target

Owned: `src-tauri/**`; `crates/session/src/session.rs` (the accessor only); `scripts/conflict-repo.sh`,
`scripts/golden-repo.sh`, new `scripts/git-sandbox.sh`.
Read-only: everything else — notably the root `Cargo.toml` (already changed by the orchestrator:
workspace `unsafe_code = "deny"`, clippy `undocumented_unsafe_blocks = "deny"`, `specta-serde`
removed), `scripts/arch-check.sh` (already fails on any `unsafe` outside `src-tauri/src/graphics.rs`,
and on more than one line containing the word `unsafe` in that file), `frontend/**` except the
generated `bindings.ts`, `docs/**`, `.omp/**`.

## Change

1. **NVIDIA guard** (plan §2 #43, architecture §3 "Arch + NVIDIA"), new `src-tauri/src/graphics.rs`,
   called as the very first statement of `run()` (before logging is set up, before
   `tauri::Builder`): on Linux only (`cfg(target_os = "linux")`), when `/sys/module/nvidia` exists
   and `WEBKIT_DISABLE_DMABUF_RENDERER` is not set at all (a user value, even `0`, is respected),
   set it to `1`. One `unsafe { std::env::set_var(..) }` block with a `// SAFETY:` comment (no other
   thread exists yet: it runs before Tauri, GTK or logging start), under
   `#[expect(unsafe_code, reason = "...")]` on the one function. The word `unsafe` appears on exactly
   one line of `graphics.rs` (arch-check counts lines). `src-tauri/src/lib.rs` drops its
   `#![forbid(unsafe_code)]` (a crate-level forbid cannot be overridden); the workspace `deny` now
   covers the crate. The decision is a small pure function over (the variable's current value, the
   path to check) so it can be tested; only the set itself is untested.
2. **Session root**: add exactly `#[must_use] pub fn root(&self) -> &Path { self.repo.root() }` to
   `impl MergeSession`; `outcome.rs` opens the session once and reads the root from it; remove the
   `yamt-gitio` dependency from `src-tauri/Cargo.toml` (src-tauri depends on `session` only,
   architecture §2).
3. Findings to fix (quoted from the reviews, with the decision):
   - #287 (boundary, should): "About 25 lines copied verbatim from scripts/golden-repo.sh (die,
     non-empty refusal, git >= 2.32 gate, RK19 config isolation, README `- File:` parsing); a change
     to how user git config is neutralised must be made twice (vision 2)." **Decision:** one sourced
     `scripts/git-sandbox.sh` holding that prelude; both scripts source it; `just golden-repo <case>
     <dir>` and `scripts/conflict-repo.sh <dir>` behave exactly as before (show both).
   - #289 (boundary, should): "Module-wide `#![allow(clippy::needless_pass_by_value)]` silences the
     lint for every function incl. helpers and tests." **Decision:** borrowed `&str` arguments where
     Tauri accepts them; a scoped `#[expect(clippy::needless_pass_by_value, reason = …)]` only on the
     commands that still need it; no module-wide allow.
   - #292 (correctness, should): "`log_accepts_a_frontend_entry_and_rejects_an_unknown_level` only
     asserts Ok(Null); it passes with the log command body replaced by () (surviving mutant)."
     **Decision:** the IPC test captures tracing around the invoke and asserts the `WARN frontend`
     line with the event and fields.
   - #293 (correctness, should): "On desktop Tauri 2.12.1 applies the CSP only to assets served
     through its own protocol; the dev window on http://localhost:5173 never applied devCsp … the
     production CSP was never exercised." **Decision:** exercise it now (Acceptance) and correct the
     claim.
   - nits riding along: #290 record `fields` as Display (`%fields`), update the expected line; #291
     delete `#![cfg(test)]` from `src-tauri/tests/cli.rs`.
