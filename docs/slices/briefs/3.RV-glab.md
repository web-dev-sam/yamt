# Slice 3.RV-glab — `yamt-gitio` runs glab; branch and remote reads; the fake glab

Board "Review a commit range" row 15 (B; needs nothing but gitio). Product rules: `docs/plan.md` §2 **#118** (glab's
run: PATH, 20 s per call, stdin closed except the JSON body, the user's environment plus `NO_COLOR=1`,
`GIT_TERMINAL_PROMPT=0`, the repository as working folder), **#119** (the branch read) — read them. Design:
`.omp/run/notes/ThreadsDesign.md` "5. Send to GitLab" ("Where glab runs", the glab calls table), "6. Only when it lines
up" ("Which merge request"), "8. Tests" (`yamt-gitio/tests/glab.rs` list and "Fake glab"), option A's "`yamt-gitio`"
block. Row 16 (lines-up and send, in `yamt-review`) builds on this API and the fake.

Facts (given):

- `crates/gitio/src/run.rs` holds the deadline runner git uses (`run.rs`, `GIT_TIMEOUT`), and the PATH lookup for git
  (`git_in(path)`): make the lookup `program_in(path, name)` with git as its first user and glab its second.
- glab 1.124.0 is not installed here; its release binary is at `/tmp/glab-probe/bin/glab` (read `glab api --help`,
  `glab auth status --help` there). Measured: `glab auth status` with no token prints the instance and "No token
  found" and exits 1. `glab api` takes `--method`, `--input -` (a JSON body from stdin, sent as
  `application/json`; `--field`s then become query parameters), `-f key=value` (on a GET, query parameters),
  `--paginate`, `-i/--include` (response headers in the output), and the `:fullpath` placeholder from the folder's
  remote. **Measure and record** (with `HOME`/`XDG_CONFIG_HOME` in a temp folder so no real token is used): what
  `glab api projects/gitlab-org%2Fcli` and an endpoint that answers 404 print on stdout/stderr and exit with, with and
  without `--include` — the fake must imitate that; if the network is unreachable say so and record what you could.
- `git rev-parse --symbolic-full-name <name>` prints `refs/heads/x`, `refs/remotes/<remote>/x`, `HEAD`… or nothing
  for a commit id; `git remote` lists remote names, one per line.

    Printed { stdout: Vec<u8> },
    Failed { status: Option<i32>, stdout: Vec<u8>, stderr: Vec<u8> },
    TimedOut,
}
pub const GLAB_TIMEOUT: Duration = Duration::from_secs(20);

}
