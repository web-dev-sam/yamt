# Slice 1.T — Tab and Shift+Tab indent the selected lines in the middle pane

Owner request (2026-10-10, finding #257): "in the editor, make tabs and shift tab add/remove
indentation of the current selected line(s)". Today Tab in the middle pane moves focus out of the
editor.

## Target

Owned: `frontend/src/editor/internal/pane.ts`, `frontend/src/editor/internal/pane.test.ts`, new
`frontend/src/editor/internal/indent.ts` and `indent.test.ts`.
Read-only: everything else — notably `editor/index.ts` and every other `editor/internal/*` file,
`theme.css`, `ui/**` (another task changes them now), `ipc/**`, configs, `docs/**`, `.omp/**`,
Rust. Needed elsewhere → stop, `deviations_from_brief`.
Non-goals: `.editorconfig`; per-language indent settings; Tab in the read-only side panes;
changing what Enter does beyond the indent unit it uses.

## Behaviour (what the user sees)

- Middle pane, Tab: one indent unit is added at the start of every line the selection touches; a
  plain cursor indents its own line. Shift+Tab removes up to one unit from each of those lines.
  The selection keeps covering the same text. One undo step per key press. Focus stays in the
  editor.
- The indent unit is the file's own: tabs when the file indents with tabs, otherwise the number
  of spaces it indents by (2 in a typical TS file, 4 in a typical PHP file). Guessed from the
  middle pane's starting text: the most common increase in leading spaces from one line to the
  next counts, 1-space steps (block-comment lines `*`) don't; no indentation found → 2 spaces.
  The same unit drives Enter's automatic indentation (it reads the same setting).
- Side panes: unchanged (read-only; Tab moves focus as today).

## Contract

- `@codemirror/commands` `indentWithTab` (`indentMore` / `indentLess`) in the middle pane's
  keymap; the unit through `@codemirror/language`'s `indentUnit` facet. No hand-written indent
  command.
- `indent.ts` exports one pure function from the document text to the unit string (`"\t"` or
  N spaces). `pane.ts` applies it only for the middle pane.
- `paneState` / `createPane` signatures unchanged.

## Tests

Behaviour, not wiring:

- the unit guessed from a 2-space TS text, a 4-space PHP text with `/** … */` doc comments, a
  tab-indented text, a text without indentation, a mostly-4 text with a few 2-step lines;
- through `paneState({ kind: "center", ... })`: `indentMore` on a 3-line selection adds the
  file's unit to all three lines (4 spaces in the PHP text, a tab in the tab text); `indentLess`
  removes it; on a line with fewer spaces than one unit it removes what is there; one `undo`
  restores the text.

`editor/` is outside the mutation run: break the guess once (take the smallest step instead of
the most common; count 1-space steps), paste the failing assertions, restore.
