# Slice 3.X-macos-tests — the Rust tests pass on macOS

The first CI run (`ci` #1, run 38449272985, `main` @ `45427b7`) failed in "Rust tests without the runner's git config"
on `macos-14` (nextest exit 100 = test failures, after 1:47). The job log needs a GitHub token we do not have, so the
failing test names are unknown. macOS never ran the tests before (the release workflow only builds).

Known cause (board row 2''' follow-up, #726/#727, triaged as kept #741/#742):
`crates/settings/tests/settings.rs:272-301` `a_chain_of_forty_settings_symlinks_is_written_through_as_linux_reads_it` is
`#[cfg(unix)]` but asserts Linux's 40-link limit; macOS resolves at most 32 links (MAXSYMLINKS) so the read fails with
ELOOP; its links use absolute targets, so a symlinked component of TMPDIR (`/var` → `/private/var` on macOS) is followed
again at every hop.
