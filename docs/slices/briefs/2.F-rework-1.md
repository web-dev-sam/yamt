## Findings to fix (quoted, with the decision)

- #313 (correctness, **block**): "The brief's minimum is 'at least every language plan §2 #29
  colours', and #29 colours every @codemirror/language-data language … The table still leaves about
  40 of those languages on the generic icon although the installed set has an icon for each.
  Examples: Dart (`file-type-dartlang`; the report wrongly says Dart has no icon), Haskell,
  Clojure/ClojureScript, Erlang, Julia, OCaml, R, Elm, Crystal, F#, Haxe, CoffeeScript, Pug, Puppet,
  Liquid, Jinja, WebAssembly, Fortran, Objective-C/C++, Stylus, Tcl, LaTeX, VB, Verilog/SystemVerilog,
  VHDL, Common Lisp, D, Cython, SAS, APL, COBOL, Gherkin, XQuery. Some languages that are mapped also
  miss extensions and file names that language-data lists: hh/hxx/h++, ino, pyw, bzl, pm,
  phtml/php3–7, ksh, psd1/psm1, mkd, xsl/xsd, hbs/handlebars, map, jsonld; and Jenkinsfile, Rakefile,
  PKGBUILD, BUILD/BUCK." **Decision:** walk every `LanguageDescription` in the installed
  `@codemirror/language-data` (its `extensions` and `filename` regexes); for each, add its extensions
  and literal file names to the table wherever `icons.json` has a fitting `file-type-*` icon (alias
  names count). List every language left on the generic icon, with the reason (no icon in the set).
  The table stays the one hand-written table in `fileIcon.ts` (ui/ may not import `@codemirror/*`,
  PM2); a test reads `@codemirror/language-data` in the `node` test project and asserts every
  extension it lists either maps to an icon or is on a named, commented list of "no icon in the set"
  — so a future language-data upgrade that adds a language fails the test until it is mapped or
  listed.
- #314 (correctness, should): "`fileIcon('toString')` is meant to prove the byName inherited-key
  guard but cannot … the name is lowercased to 'tostring'." **Decision:** test `constructor` and
  `__proto__` as file names (both reach the byName lookup lowercased) → generic icon.
- #312 (boundary, nit): one `lookup(table, key)` helper used at both sites; results named `icon`.
