## Contract (fixed; you may add, never change)

```ts
// ipc/domain.ts: export type RangeFileId (brand); export function isRangeFileId(value: number): value is RangeFileId
// ipc/rangeDomain.ts: camelCase shapes RangeStart, RangeSide (shortId), RangeSideLabel, RangeEntry, RangeChange
//   (renamed: oldPath), RangeLineCounts, RangeFile (texts: differences as compareDomain's Difference), RangeEntryKind,
//   RangeModeChange, RangeSides; toRangeStart(raw), toRangeFile(raw) (reusing toDifferences)
// ipc/RangeSource.ts
export interface RangeSource extends SettingsSource {
  openRange(): Promise<SourceResult<RangeStart>>; // the sides and every changed file
  loadRangeFile(file: RangeFileId): Promise<SourceResult<RangeFile>>; // one file's view, decided by Rust
}
// ipc/tauriRange.ts:   export function createTauriRangeSource(...): RangeSource      (as createTauriCompareSource)
// ipc/fixtureRange.ts: export function createFixtureRangeSource(log, search: string): RangeSource
//   `?range` → case "review"; `?range=<case>` → that case; unknown → logs `range.fixture_miss`, lists nothing
// ipc/index.ts exports all of the above
```

`ui/problemText.ts`: `UnknownRangeFile` → the fixed reason "that file is not part of this range."
