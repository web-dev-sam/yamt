## Behaviour

1. **Stored split**: valid when both shares are finite, each ≥ `MIN_SHARE` (0.01) and their sum ≤ 0.99; anything else
   (missing, not JSON, wrong types, a zero or negative pane) reads as `EQUAL_SPLIT`; a missing key writes nothing.
2. **`paneColumns`**: per pane `minmax(min(220px, calc((100% - 2 * <gutter>) / 3)), <share × 100>fr)`, gutters
   `2.5rem` (strip) or `1px` (gap); every fr factor ≥ 1 (factors summing below 1 leave part of the row empty,
   css-grid §12.7.1).
3. **`dragged`**: `T` = the three widths' sum, `min` = `Math.min(220, T / 3)`. For the `local` boundary: `pair` = local
   - center, `floor` = `Math.min(min, pair / 2)`, `local' = clamp(local + dx, floor, pair − floor)`, remote keeps its
     measured width exactly; the result is `{ local: local' / T, remote: remote / T }`. `remote` mirrors it. `dx` is from
     the press, so the grab point holds. dx 0 gives the measured shares.
4. **`useColumnDrag`**: an accepted main-button press cancels the event (and the matching `mousedown`, so the keyboard
   and selection stay), captures the pointer on the handle, adds `COLUMN_RESIZING_CLASS` to `root` (default
   `document.documentElement`), sets `dots` to `drag` and calls `press`; each move calls `moveBy(clientX − pressX)` and
   reads no layout; up, cancel, lost capture and scope dispose end it and remove the class; a second pointer's moves are
   ignored; a rejected target or another button does nothing and cancels nothing; a double-click on an accepted target
   calls `reset`, elsewhere nothing; hover: accepted target → `hover`, rejected → `rest`, leave → `rest`.
5. **`usePaneDividers`**: accepts a press whose target is the handle itself or the strip's `<svg>` root (an icon or a
   wave join inside the svg is rejected, so the editor keeps its presses); `press` measures once and each move calls
   `setPaneSplit(dragged(…))`; `reset` → `resetPaneSplit`.
6. **File list width**: valid when finite and ≥ 160, else `null`; `setWidth` clamps to `[160, windowWidth / 2]`;
   `resetWidth` → `null` (stored as removed or as the default: say which).
