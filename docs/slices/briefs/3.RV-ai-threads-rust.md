## Contract (fixed; you may add, never change)

```rust
// thread_types.rs
pub enum MessageBody { Note { text: String }, AiAnswer { session: String, turn: u32 } }
// thread_store.rs
/// Stores the conversation the thread's next "Ask AI" continues; replaces an earlier one (#115: omp lost it).
pub fn set_session(&mut self, range: &Range, thread: ThreadId, session: &str) -> Result<ThreadList>;
/// Sets the session as above when it differs, then appends `AiAnswer { session, turn }` with
/// turn = the number of `AiAnswer`s of that session already in the thread (the one numbering rule).
pub fn add_ai_answer(&mut self, range: &Range, thread: ThreadId, session: &str) -> Result<ThreadList>;
// src-tauri/src/review.rs — two commands, registered like the others
set_thread_session(thread: ThreadId, session: String) -> Result<ThreadList, IpcError>
add_ai_answer(thread: ThreadId, session: String) -> Result<ThreadList, IpcError>
```

An unknown thread answers the existing `UnknownThread`. An AI answer's `posting` starts `NotQueued`, like a note's.

## Acceptance

second `set_session` replaces it; answers number 0, 1, 2 within a session; after a session change the next answer is
turn 0 of the new session and the older answers keep theirs; format 1 round-trips `aiAnswer` with its session; an
unknown thread is refused with nothing written. A shell test that both commands reach the store. Your tests kill the
