## Behaviour (plan #70 and the design, settled; decided points marked "owner" are the orchestrator's, #876)

1. **Project folders:** for each conflicted file, the nearest folder with a `package.json` walking up to the
   repository root (the file's own folder first); each distinct project is checked once.
2. **Presets** (`presets.ts`, one table; the design's §1 table): oxlint (`oxlint` found in the project's
   `node_modules/.bin` up to the root: `place === "Project"`; `oxlint --lsp`; initializationOptions
   `[{ workspaceUri, options: { run: "onType" } }]`), oxfmt (`oxfmt --lsp`, formats: true), TypeScript (a
   `tsconfig.json` or `jsconfig.json` in the project plus the project's `node_modules/typescript/package.json`
   version: 7 or later → `tsc --lsp --stdio`; `@typescript/native-preview` installed → `tsgo --lsp --stdio`; 5.x or
   6.x → `typescript-language-server --stdio`, found in the project or on PATH, else `install` with reason
   `{ kind: "typescript", version }`), eslint (a config `eslint.config.{js,mjs,cjs,ts,mts,cts}` or
   `.eslintrc{,.js,.cjs,.json,.yaml,.yml}` plus `node_modules/eslint/package.json`; `vscode-eslint-language-server
   --stdio` found in the project or on PATH, else `install` with reason `{ kind: "eslint" }`; settings
   `{ validate: "on", run: "onType" }` answered for `workspace/configuration`). File types per the design's table.
   Global installs do not count for oxlint, oxfmt or TypeScript itself.
3. **Package manager** (`packageManager.ts`, for `InstallHint.manager`): the `packageManager` field of the project's
   `package.json` (`npm@…`, `pnpm@…`, `yarn@1…` → `yarn`, `yarn@2+` → `yarnBerry`, `bun@…`), else the lock file
   nearest the project folder up to the repository root (`pnpm-lock.yaml`, `yarn.lock` → `yarn`, `bun.lock` /
   `bun.lockb`, `package-lock.json`; a lock file answers `Text`, `TooLarge` or `NotText` — all mean "exists"), else
   `null`. `folder` = the project folder.
4. **At start** (after the first file list and the settings load): `detect` + `addedSpecs`; when the list is empty,
   nothing. When the repository (the host context's root, the same string Rust keys the answer by) has no stored
   answer: the question "Start this project's language servers?", one line per server ("oxlint, oxfmt, TypeScript —
   frontend/"; "pylsp — added by you"; a not-installed one included, marked "not installed"), then "yamt remembers your
   answer for this repository. You can change it in Settings."; buttons **Start** / **Don't start** (both stored with
   `setServerAnswer`); Escape stores nothing and the question comes back next run. Then
   `setSpecs(specs, { startOnOpen: answer === "start" })`. Fixture mode (no host): nothing at all.
5. **On window focus** (owner): detection runs again and `setSpecs` reconciles (unchanged specs keep running; a
   server installed meanwhile starts when the answer is Start). Never asks; a repository still without an answer keeps
   its servers stopped.
6. **Settings → "Language servers"** (`LanguageServerSettings.vue`, after Keymap): "This repository" with the root
   path and Start / Don't start (`ChoiceButtons`), "Not asked yet" when there is none (changing it applies at once:
   `setSpecs` again with the new `startOnOpen`; Don't start stops running servers); "Found in this repository": the
   detected servers, read-only (name, project folder, command or "not installed"); "Added by you": one row per added
   server (command, file types, Remove), and a form with **Command** (split on spaces) and **File types**
   (extensions, commas or spaces, leading dots dropped) and Add; an empty field disables Add.
7. **Smoke repository**: a script that builds a conflict repository whose project has `package.json`,
   `.oxlintrc.json`, `.oxfmtrc.json`, `tsconfig.json`, a lock file, and `node_modules` linked to `frontend/node_modules`
   (oxlint, oxfmt, typescript 5.9 present; no `typescript-language-server`), with conflicts in `.ts` files.

   with real keys and pointer; screenshots.

   oxfmt, TypeScript (not installed) for the project folder; Start; the status area shows oxlint and oxfmt running and

   oxfmt and saves; restart the app: no question; install `typescript-language-server` into the smoke project
