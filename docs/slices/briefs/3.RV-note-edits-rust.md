# Slice 3.RV-note-edits-rust — edit and delete an unsent note: store and commands

Board "Review a commit range" row 15 (owner answer #1636). Product rules: `docs/plan.md` §2 **#123** (read it; it
amends #120), with #117 (the store, its one writer, the send guard's lock order) and #121 (AI turns numbered by the
stored answers). Row 16 (the window) builds on this surface once round 1 is committed.

Facts (given):

- `crates/review/src/thread_store.rs`: `ThreadStore` is the only writer of `threads.json`; every change clones
  `self.file`, edits the clone, then `commit(next)` (writes only when it differs; a failed write keeps the old file).
  `change_posting` shows the checks to reuse: the message must be on a file of `range` (`UnknownMessage`), a `Pending`
  posting refuses (`MessagePending`); `require_text` refuses blank text (`EmptyMessage`). `Thread.messages` is "never
  empty" (`thread_types.rs:117`). Ids come from `take_thread_id`/`take_message_id` and are never reused.
- `crates/review/src/thread_store/waiting.rs`: a send reads a waiting message's text again before each post
  (`waiting_text`) and records the result only while the message still waits with that text (`record_if_waiting`,
  which answers `UnknownMessage` for a message that is gone).
- `src-tauri/src/review.rs`: `send_guard(&state.sending)` answers `IpcError::SendRunning` while a send holds it;
  `send_queue` holds it for the whole send. `src-tauri/src/ipc_error.rs` maps each `yamt_review::Error` to an
  `IpcError` kind (tests in `ipc_error/tests.rs`); commands are registered in `src-tauri/src/commands.rs`.

## Contract (fixed; you may add, never change)

```rust
// crates/review
impl ThreadStore {
    /// Replaces a note's text; a queued or refused note keeps waiting with `text` as what is sent (#123).
    pub fn edit_note(&mut self, range: &Range, message: MessageId, text: &str) -> Result<ThreadList>;
    /// Removes a note; a thread left with no message is removed (#123).
    pub fn delete_message(&mut self, range: &Range, message: MessageId) -> Result<ThreadList>;
}
pub enum Error { /* … */
    /// The message is an AI answer, which is never edited or deleted.
    NotANote { message: MessageId },
}
// src-tauri: #[tauri::command] edit_note(message: MessageId, text: String) -> Result<ThreadList, IpcError>
//            #[tauri::command] delete_message(message: MessageId) -> Result<ThreadList, IpcError>
// both take send_guard first (SendRunning while a send runs), then the store; IpcError::NotANote { message }
```

Rules, in order of the checks: unknown or not on a file of `range` → `UnknownMessage`; an `AiAnswer` → `NotANote`;
`Pending` → `MessagePending`; edit only: blank → `EmptyMessage`. Edit: `Note.text` = `text`; `NotQueued` stays;
`Queued { .. }` and `Refused { .. }` become `Queued { text }`. Delete: the message leaves its thread; an empty thread
leaves the file; the thread's `session` is not touched while the thread stays. A refused check writes nothing. Keep
`record_if_waiting`'s answer for a gone message as it is: the send guard makes delete-during-send unreachable.
