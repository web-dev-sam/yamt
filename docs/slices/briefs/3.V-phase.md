Cause (measured, `/tmp/uv/zoom-joins.png`): each pane's mask tile starts at its crest from the pane's

## Contract (fixed; the toggle slice relies on it)

`connectors/index.ts` (pure, tested on numbers, mutated):

```ts
export const WAVE_DOWN_X = WAVE_STEP_PX; // the tile crosses its centre line heading down
export const WAVE_UP_X = 3 * WAVE_STEP_PX; // … heading up
export type WaveEnds =
  | { readonly kind: "leaves"; readonly at: number } // a strip on the pane's right only
  | { readonly kind: "enters"; readonly at: number } // a strip on the pane's left only
  | { readonly kind: "through"; readonly enters: number; readonly leaves: number };
export type WavePhase = { readonly offset: number; readonly period: number }; // px from the wave's left edge
export function wavePhase(waveLeft: number, ends: WaveEnds): WavePhase;
```

- `leaves`: period 20, phase at `at` = `WAVE_DOWN_X`; `enters`: period 20, phase at `at` = `WAVE_UP_X`.
- `through`: `D = leaves − enters`; `k = max(0, round(D/20 − ½))`; period `P = D/(k + ½)`; phase at
  `enters` = `WAVE_UP_X·P/20`, so the phase at `leaves` is `WAVE_DOWN_X·P/20`; `D ≤ 0` falls back to
  `enters`.
- `0 ≤ offset < period` always; a modulo that handles negative numbers (JavaScript's `%` does not).

`editor/internal/wavePhase.ts`:

```ts
export const WAVE_PHASE_VARS = { offset: "--fold-wave-x", period: "--fold-wave-period" } as const;
export type WaveHosts = Readonly<Record<Pane, HTMLElement>> & {
  readonly strips: readonly [Element, Element];
};
export class WavePhases {
  constructor(hosts: WaveHosts, views: () => PaneViews);
  destroy(): void;
}
```

(`foldView.ts`'s private `FoldHosts` becomes `WaveHosts`. If the hosts `editor/index.ts` passes do not
fit `WaveHosts`, report the one-line change in `deviations_from_brief` instead of making it.)

plus the pure helpers the design names (`paneEnds`, `phaseStyle`), tested in node. `paneEnds` derives
which pane leaves/enters at which strip edge from `STRIP_PANES` (`geometry.ts`), never from a second
table: the left pane leaves at the left strip's `<svg>` left edge, the middle enters at its right edge
and leaves at the right strip's `<svg>` left edge, the right pane enters at the right strip's right edge.

**Correction to the design:** `waveLeft` is the left edge of each pane's **scroller**
(`view.scrollDOM.getBoundingClientRect().left`), not the host's: the `.fold-wave` sits at `left: 0` in
the line-number gutter, the only gutter (`pane.ts:251`), which CodeMirror keeps sticky at the scroller's
left edge. Measuring the element the mask hangs from removes the design's "host left equals wave left"
[INFERENCE].

`WavePhases`: one `ResizeObserver` on the three pane hosts; its callback reads the three scrollers' and
the two strips' rects, computes each pane's phase and writes both custom properties on that pane's host
with `style.setProperty`, only when the value changed. No read per scroll frame (#51). `destroy()`
disconnects and removes the properties (CM14).

`foldView.ts`: `tile.maskPosition` = `var(--fold-wave-x, 0px) <waveTop>px`, `tile.maskSize` =
`var(--fold-wave-period, 20px) <WAVE_TILE_HEIGHT_PX>px` (build the strings from `WAVE_PHASE_VARS` and the
constants); the `-webkit-` twins follow; the mask `<svg>` gets `viewBox='0 0 20 8'` (from the constants)
and `preserveAspectRatio='none'` so a stretched period stretches the tile instead of clipping it; the 2 px
hover mask the same. `class Folds` creates `WavePhases` in its constructor and destroys it in
`destroy()`.
