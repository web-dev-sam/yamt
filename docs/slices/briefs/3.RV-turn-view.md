## Contract (fixed; you may add, never change)

```ts
// <AiTurn :turn="TurnView" :end="TurnEnd | null" :client="AgentClient" @retry />  — "Thinking and steps" collapsed,
//   live while running and openable after; each step (title, status, output; an edit as EditDiff); the answer through
//   useMarkdown; a stopped line or one failure sentence with Retry
// <AgentSettings />  — "Agent command" (field, Use, Default, the yolo note) and "First message" (text area, Use,
//   Default, the five placeholders, each unknown one named)
// ui/aiClose.ts
export function aiMayClose(target: { readonly source: AgentSource; readonly asking: Asking; readonly report: … }): Promise<boolean>;
// Missing or Clean → true without asking; Changed / Unreadable → the question; Keep → true; Discard → discardCheckout,
// true on success, a problem and false on failure; dismissed (Escape) → false
// ui/question.ts gains the kinds keepAiChanges { folder, files, headMoved, refs } (refs: the AI's branches and stash,
//   plan #122, named like the moved HEAD) and keepUnreadableCheckout { folder, message }
//   with confirm "Keep Changes" (preferred) and cancel "Discard Changes"
// ui/editDiffLines.ts: export function editDiffLines(oldText, newText, differences): readonly DiffRow[] (pure)
// ui/aiText.ts: one sentence per AgentFailure kind (exhaustive), the step words, "Edited <path>", "Created <path>"
```
