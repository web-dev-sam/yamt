## Behaviour (plan #123)

1. A note (`body.kind === "note"`) whose posting is not `pending` shows **Edit** and **Delete** beside Post; an AI
   answer and a pending note show neither.
2. **Edit** turns the message into a writing box holding its text, with the box's keys (Ctrl/Cmd+Enter saves, Escape
   cancels, keys stay in the box); a blank text is not saved; the saved list replaces the old one (`replace`); focus
   returns to the message's Edit button after save or cancel. A message's Edit and Post boxes are never open at once.
3. **Delete** asks "Delete this comment?" (Delete / Cancel); Delete removes it; Cancel or Escape keeps it. A thread
   whose last message goes disappears with its line mark and file count; its open state and any draft of it go too.
4. Both are off (disabled, with a hover text saying why) while a send runs and while the AI works in that thread.
   A refusal from Rust is reported through the existing problem path with a reason for `NotANote`.
