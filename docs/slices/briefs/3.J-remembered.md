## Contract (fixed; you may add, never change)

```rust
// gitio
impl Repo {
    /// The paths rerere still tracks (`MERGE_RR` through `--git-path`, records `<id>[.<n>]\t<path>\0`); None when
    /// there is no `MERGE_RR` (rerere off, or nothing recorded at this stop).
    pub fn rerere_tracked(&self) -> Result<Option<Vec<PathBuf>>>;
}
// session
pub enum FileStatus { Unresolved, Remembered, Resolved }     // Remembered: unmerged for git, rerere's text on disk
pub enum Waiting { SideLines, Markers { .. }, AsShown, Remembered }  // Remembered: Save writes the Result as shown
```

## Behaviour

1. **Detection at open** (#90): `MERGE_RR` exists, the path is not in it, git's re-run output for the path has conflict
   blocks, the disk file has none → `AtOpen::Remembered`, first seen `Seen::ViewRemembered` (seen equals the disk, so
   nothing settles or stages it). Every other case as today (a hand fix with rerere off is still staged by #52).
2. **Status:** `Remembered` while git lists the path unmerged and the file is still in that view; `finish` (Mark
   resolved) stages it → `Resolved`; Save keeps `Remembered`; Reset writes the at-open (remembered) bytes and keeps it;
   a later disk change follows #52 (`ViewFromDisk`, settled as today). The exit status and `remaining()` count it as
   unresolved.
3. **View** (design view (b), `session/src/remembered.rs`): the Result is the remembered text (`Middle::Disk`); each
   block git wrote is a `Conflict` chunk located in the stages exactly as the disk view locates a block, its Result lines
   found by `line_map(git output, remembered).covering(block)`, `waiting: Remembered`; sides show their changes and
   words as on any conflict; one-sided changes outside the blocks are not chunks (they are already in the text).
4. **Window minimum:** `fileText.ts` writes a `Remembered` chunk as shown; `nextFile.ts` treats `Remembered` as not yet
   resolved; `ipc/fixture.ts` accepts both new values; fixture mode can show one remembered file (`?remembered=<path>`
   over a fixture, or a showcase case through `yamt-cli fixture` — your choice, say which).
