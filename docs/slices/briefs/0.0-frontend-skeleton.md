# Slice 0.0' — frontend walking skeleton

## Target
Owned: `frontend/**` (everything under it, including `frontend/scripts/`, `frontend/package.json`,
`frontend/pnpm-lock.yaml`), `frontend/src/ipc/bindings.ts` is NOT yours (generated by the Rust
side; if absent, create `frontend/src/ipc/.gitkeep` only).
Read-only: `docs/**`, `.omp/**`, `AGENTS.md`, `justfile` (may not exist yet; its `web-*` recipes
will call `pnpm -C frontend lint|typecheck|test|sfc-order|dev` — those package scripts must exist).
Non-goals: any CodeMirror code, any Vue component beyond `App.vue` rendering the text "yamt",
any Tauri code, any store logic.

## Contract
- pnpm, Vite 6+, Vue 3.5+, TypeScript 5.8+, Tailwind v4 (`@tailwindcss/vite`), `@vueuse/core`
  installed but unused, `valibot` installed but unused.
- `tsconfig.json`: `strict`, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`,
  `verbatimModuleSyntax`, `noImplicitOverride`, `noFallthroughCasesInSwitch`, `isolatedModules`,
  `moduleResolution: bundler`. `vue-tsc` for typecheck.
- Lint: `oxlint` + `oxlint-tsgolint` (`typeAware: true`), config `frontend/.oxlintrc.json` with:
  `no-explicit-any`, `no-non-null-assertion`, `consistent-type-assertions` (never, override allows
  `src/ipc/fixture.ts`), `no-console` (override allows `src/ipc/log.ts`), `func-style: declaration`,
  `no-magic-numbers` (ignore 0, 1, -1; ignore in `*.test.ts`), `import/no-cycle`, type-aware
  `switch-exhaustiveness-check`, `no-unnecessary-condition`, `strict-boolean-expressions`,
  `no-floating-promises`, and `no-restricted-imports` **overrides** implementing
  `skill://project-map` PM2/PM3/PM5:
  - `src/ui/**`: deny `@codemirror/*`, `../editor/internal/*`, `**/internal/*`, `../model/*`
  - `src/editor/**`, `src/model/**`, `src/connectors/**`: deny `vue`, `@vueuse/*`, `@tauri-apps/*`
  - `src/**` except `src/ipc/**`: deny `./bindings`, `../ipc/bindings`
- Format: `oxfmt` with `sortImports` and `sortTailwindcss` enabled (`frontend/.oxfmtrc.json`).
- ESLint: `eslint.config.js` with `eslint-plugin-vue` flat recommended only, files `**/*.vue`,
  plus `vue/block-order`, `vue/define-macros-order`, `vue/define-props-declaration: type-based`,
  `vue/define-emits-declaration: type-based`, `vue/require-typed-ref`. No typescript-eslint.
- `frontend/scripts/check-sfc-order.ts`: parses every `src/**/*.vue` with `@vue/compiler-sfc`,
  classifies top-level statements of `<script setup>` into the order from
  `skill://vue-conventions` VU2 (imports → types → macros → ref/reactive/shallowRef/useTemplateRef →
  computed → watch/watchEffect → lifecycle → function declarations); exits 1 with `file:line`
  on the first out-of-order statement. Run with `tsx` or `node --experimental-strip-types`
  (your choice; report which).
- Test: Vitest with two projects: `node` for `src/model/**`, `src/connectors/**`, `src/ipc/**`;
  `browser` (Playwright **webkit** provider, `@vitest/browser`) for `src/editor/**`. One trivial
  test in each project so both runners are proven. If WebKit cannot launch on this machine,
  keep the config, mark the browser project with `--project node` as default in the `test`
  script, and report the exact launch error in `deviations_from_brief`.
- package scripts: `dev` (`VITE_CHUNK_SOURCE=fixture vite`), `build`, `lint` (oxlint type-aware +
  eslint on `src/**/*.vue`), `fmt` / `fmt:check` (oxfmt), `typecheck` (vue-tsc --noEmit),
  `test` (vitest run), `sfc-order`.
- Directories created with `.gitkeep`: `src/ipc`, `src/model`, `src/editor`, `src/connectors`,
  `src/ui`, `fixtures`. `src/main.ts` mounts `src/ui/App.vue`; `App.vue` renders "yamt" with one
  Tailwind class. `src/ipc/log.ts` with the `log` object from `skill://ipc-contract` IPC8 (console
  mirroring only; the Tauri forward is a `forward?: (entry) => void` parameter defaulting to none).

## Change
1. Scaffold with `pnpm create vite` (vue-ts) then strip to the contract; pin versions in
   `package.json` exactly (no `^`).
2. Tooling configs, lint fences, formatter, SFC-order script, Vitest projects.
3. `log.ts` + its `log.test.ts` (node project): a `warn` call produces one console line with the
   event name and the fields, and calls `forward` once with the entry.
4. Prove the fences: temporarily add `import "vue"` to a file under `src/editor/` and
   `import "@codemirror/state"` to a file under `src/ui/`; `pnpm lint` must fail naming both;
   remove them. Temporarily reorder a `<script setup>` in `App.vue` (a `function` before a
   `computed`); `pnpm sfc-order` must fail with file:line; restore.
5. `pnpm lint && pnpm typecheck && pnpm test && pnpm fmt:check && pnpm sfc-order` once, at the end.

## Acceptance
- All five commands in step 5 exit 0 (paste the tail of each).
- Fence proof from step 4 pasted (the failing lint lines, the failing sfc-order line).
- `pnpm test` output shows both Vitest projects (node + browser) with ≥ 1 passing test each, or the
  verbatim WebKit launch error.
- `pnpm dev` serves and Epiphany (or any WebKit browser; else Chromium, say which) shows "yamt".
