Facts (given, CodeMirror 6.43.14, `node_modules/@codemirror/view/dist/index.js`):

- A widget ignores every event by default (`ignoreEvent() { return true }`, :161); the editor's key and selection
  handling skip such widgets (:4903, :7276); CodeMirror sets `contentEditable="false"` on a widget's DOM (:2183); it
  observes only `scrollDOM` for resizes (:7208), so a growing widget must call `requestMeasure` itself; it re-measures
  heights when the content's height changes (:6363). Block decorations must come from a `StateField`, never a plugin.
  `lineNumbers()` merges `domEventHandlers` across configs (:11806–11866); a `lineNumberMarkers` marker with `toDOM`
  replaces the number (:11836).
- Row 4 (`editor/range.ts`): `RangeController(texts, hosts, options)` over `createReadOnlyColumnViews(…, { settings,
  updated, extensions })` (the seam for a per-column field), `CompareFrame` (`editor/internal/compareFrame.ts`: rows
  cached until spans, heights or docs change; `rowsChanged(update, fields)`; `measure` anchors for scroll sync),
  `CompareStrip` (bands from `lineBlockAt`, which already counts block widgets above a line). The compare window's
  `editor/compare.ts` builds `CompareFrame` too and must behave exactly as before.
- `yamt_merge_core`'s `Difference { left: { start, len }, right: { start, len }, words }` in `LeftLine`/`RightLine`
  (0-based) reaches the editor as `Difference` from `../ipc`; `LeftLine`/`RightLine` are brands in `ipc/domain.ts`.
- `~icons/lucide/message-square-plus?raw` is available through the icon plugin (the `?raw` form is the only one
  framework-free modules may import, `frontend/scripts/fences.ts`).

## Contract (fixed; you may add, never change)

```ts
// ipc/threadLine.ts (exported from ipc/index.ts): the domain anchor, mirroring the Rust ThreadLine of plan #116
export type ThreadLine =
  | { readonly kind: "removed"; readonly left: LeftLine }
  | { readonly kind: "added"; readonly right: RightLine }
  | { readonly kind: "unchangedOnLeft"; readonly left: LeftLine; readonly right: RightLine }
  | { readonly kind: "unchangedOnRight"; readonly left: LeftLine; readonly right: RightLine };
export function shownColumn(line: ThreadLine): Column; // "left" | "right", exhaustive

// editor/range.ts (public; editor/index.ts adds: export type { ShownThread, RangeEvents } from "./range")
export type ShownThread = {
  readonly key: string; // opaque, built by ui (`thread-12`, `draft-3`)
  readonly line: ThreadLine;
  readonly shown: "open" | "collapsed" | "draft"; // draft: a row, no count; collapsed: a count, no row
};
export type RangeEvents = {
  readonly startThread: (line: ThreadLine) => void; // a press on a line number
  readonly toggleThreads: (keys: readonly string[]) => void; // a press on a count mark: that line's threads in that column
  readonly hosts: (hosts: ReadonlyMap<string, HTMLElement>) => void; // after each showThreads that adds or drops a key
};
export class RangeController {
  constructor(texts: RangeTexts, hosts: CompareHosts, options: RangeOptions, events: RangeEvents);
  setPreferences(preferences: Preferences): void;
  moveToChange(direction: Direction): void;
  showThreads(threads: readonly ShownThread[]): void;
  destroy(): void; // also drops every host
}
// editor/internal/compareFrame.ts: CompareFrame takes { views, strip, fields, anchors }; the compare window passes
// [differenceField] and no extra anchors (unchanged behaviour), the range window [differenceField, threadField] and
// threadAnchors.
```

## Change

As the design's option A "Internal": `threadAnchor.ts` (pure `anchorAt(differences, column, line) → ThreadLine`),
`threadRows.ts` (pure `threadRows(spans, shown)` → `ThreadRow { place: Record<Column, number>; keys: Record<Column,
readonly string[]> }`; the gap's place for removed, added and unchanged lines; one row per place; order kept by the
other column's place; collapsed threads place no row, drafts do), `threadField.ts` (one `StateField` per column set by
an effect; `Decoration.widget({ block: true, side: 1 + k })` at the end of line `place − 1`, `side: -1` at 0 for place
0), `threadWidget.ts` (`ThreadRowWidget` `eq` by row key and keys only — never by height; `toDOM` makes
`div.cm-thread-row` with its height from the shared `RowHeights` and appends that column's persistent hosts;
`estimatedHeight` from `RowHeights`; `destroy` keeps the hosts), `threadHosts.ts` (`ThreadHosts`: one host element per
key for the controller's life; one `ResizeObserver` on every host; row height = the larger column's summed box heights
written on both cells, then `requestMeasure()` on both views; `--thread-left`/`--thread-width` on each column host so
the row stays put under horizontal scroll), `threadNumbers.ts` (merged `lineNumbers({ domEventHandlers: { mousedown }
})`: a press on a number → `startThread(anchorAt(...))`, on a count badge → `toggleThreads(keys)`;
`lineNumberMarkers` drawing the number plus a badge in the cell's left padding so the gutter's width never changes;
the hover icon as a CSS mask from `message-square-plus?raw`, coloured `--color-fg-muted`, no colour literal).
`CompareFrame` gains `fields` and `anchors`; rows outside differences become scroll anchors (the bottom of the line
above and the top of the line below, in both columns), merged sorted.
