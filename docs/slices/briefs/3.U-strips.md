## Change

1. `connectors/index.ts`: `waveJoinPath(join: { left: number; right: number }, width: number): string`
   — WebStorm's `DiffLineSeparatorRenderer.drawConnectorLine` with x1 = 0, x2 = width, y1 = `left`,
   y2 = `right` (both already the wave's centre y), step `WAVE_STEP_PX`, h `WAVE_HALF_HEIGHT_PX`:
   ```
   if |y2-y1| / width < 0.2:
     if width > 5·s: M x1 y1; Q x1+.5s y1+h, x1+s y1+h; Q x1+1.5s y1+h, x1+2s midY;
                     Q x1+2.5s midY-h, midX midY-h; Q x2-2.5s midY-h, x2-2s midY;
                     Q x2-1.5s y2+h, x2-s y2+h; Q x2-.5s y2+h, x2 y2
     else:           M x1 y1; Q midX midY+2h, x2 y2
   elif y1 > y2: M x1 y1; C x1+s/8 y1+h/8, x1+s/8 y1+h/2, x1+s/2 y1+h/2; C x2-2s y1+h/2, x2-2s y2+4h, x2 y2
   else:          M x1 y1; C x1+2s y1+4h, x1+2s y2+h/2, x2-s/2 y2+h/2; C x2-s/8 y2+h/2, x2-s/8 y2+h/8, x2 y2
   ```
   (WebStorm's `x1 − 0.5` start is a Java2D mirroring fix; leave it out.)
2. `geometry.ts`: `waveRows` — per run, each pane's document-space top of its displayed wave block
   (`lineBlockAt(displayed.from).top`) or `null`; computed inside the layout cache (no layout read per
   scroll frame, #51); the frame's `Layout` carries it.
3. `gap.ts`: `wavePaints` beside `bandPaints`: for the strip between two panes, a join for each run
   where **both** panes display a wave (WebStorm `MyPaintable.process`), y = top + that pane's shift +
   `waveCenterY(lineHeight)`, kept only when it crosses the strip (`crossesStrip`).
4. `strips.ts`: a wave layer between the bands and the icons; per run one kept `<g data-fold-run="k">`
   with a transparent hit path (stroke one line height wide, `pointer-events: stroke`) and the visible
   path (`stroke: var(--color-diff-wave)`, 1 px, 2 px under `.fold-wave-hover`, no fill), its `d`
   updated per frame like the bands; a node created while its run is hovered starts with the class.
   Drawn in read-only views too (no icons there, the waves stay).
5. `theme.css`: the strip wave's stroke rules and `cursor: pointer` on the hit path.
