## Findings to fix (quoted, with the decision)

- #366 + #372 (boundary and correctness, **block**): "A deb-installed or source-built yamt started
  from any process that leaked [APPIMAGE and OWD] resolves the default `.` against the parent's
  OWD … the wrong repository or exit 2. This is a regression." **Decision:** the process counts as
  inside an AppImage only when `APPIMAGE` and `APPDIR` are set and `std::env::current_exe()` lies
  under `$APPDIR`. `repo_from_start_dir` computes that and passes it to the pure `resolved`. Tests:
  variables set but the binary outside `APPDIR` → the repo stays as given.
- #376 (correctness, nit): "If OWD is set but empty, `PathBuf::from("").join(".")` stays relative
  and resolves against $APPDIR/usr." **Decision:** use OWD only when it is a non-empty absolute
  path; test `Some("")` and a relative OWD.
- #367 + #373 (boundary and correctness, **block**): "'run `yamt` in the repository' and the
  `!yamt` git alias work only for the .deb … The AppImage and the macOS .app never put `yamt` on
  PATH … Starting the app from the file manager or Finder … exits 2 with no window." **Decision:**
  Install gets one PATH line per format — AppImage `install -m755 yamt_0.1.0_amd64.AppImage
  ~/.local/bin/yamt`; macOS `sudo ln -s /Applications/yamt.app/Contents/MacOS/yamt
  /usr/local/bin/yamt` after the first right-click → Open — and Use gets one sentence: yamt starts
  from a terminal inside a repository; double-clicking it shows nothing. Check the exact AppImage
  file name tauri produces and use it.
- #368 (boundary, should): "The release artifacts carry neither LICENSE nor THIRD_PARTY_NOTICES.md,
  and the notices file gives licence counts instead of the copyright and licence texts that
  MIT/BSD/ISC/Apache-2.0 require for binary redistribution … the LGPL GTK/WebKitGTK copies in the
  AppImage get only a pointer to the upstream sites, without the Ubuntu 22.04 versions."
  **Decision:** one script in `scripts/` (no new tool: `cargo metadata`, `pnpm licenses list --prod
  --json`, and the licence files already on disk) writes one committed full-text file — copyright
  lines and licence texts for every bundled Rust crate and production JS package, the hand-checked
  parts (JetBrains Mono OFL, Lucide, vscode-icons) kept — and `THIRD_PARTY_NOTICES.md` stays the
  short human summary pointing to it. `bundle.resources` ships `LICENSE` and the full-text file in
  every bundle. The LGPL libraries the AppImage carries are named by Ubuntu 22.04 source package;
  the Linux release job appends their exact installed versions (`dpkg-query`) to the shipped file
  before bundling. If the script cannot find a licence text for a package, it fails naming it
  rather than skipping it.
- #369 (boundary, should, RS16): "`is_page_gone(&mut self, …)` reads like a query but drains the
  answer channel and overwrites `unanswered_since` … the tests have to drive the mutable struct and
  poke its private `answer_sender`." **Decision:** a pure `fn page_gone(unanswered_since:
  Option<Instant>, request_at: Instant) -> bool` the tests call directly, and a
  `record_close_request(&mut self, at)` that drains the answers, calls it and stores `at`.
- #375 (correctness, should): "There is no minimum age for 'unanswered': a second close request
  100 ms after the first destroys the window if the ping has not come back yet. A double-click on ×
  while the page's JS is busy … closes a live page without its 'Cancel File Merge' question and
  loses unsaved work." **Decision:** a named `UNANSWERED_CLOSE_GRACE` of 1 s: the page counts as
  gone only when the earlier request has been unanswered for at least the grace and at most
  `UNANSWERED_CLOSE_TIMEOUT`; a request inside the grace keeps the earlier `since`. Boundary tests
  at grace − 1 ms, grace, timeout, timeout + 1 ms.
- #374 (correctness, should): "The `!result.is_empty()` check is the only thing separating a dead
  page from a live one, and no test covers it (#353) … wry 0.57 hands "" to the callback on failure
  on both webkitgtk (mod.rs:799-805) and macOS (wkwebview/mod.rs:740-754)." **Decision:** `fn
  answered(result: &str) -> bool { result == <the ping's expected JSON> }`, unit-tested with `""` →
  false and the expected answer → true; the comment cites both wry call sites.
- #370 (boundary, should): "The module guide lists every src-tauri file except the new
  `appimage.rs`, and still calls `window.rs` 'the one window' with no close fallback."
  **Decision:** add both to `src-tauri/AGENTS.md`.
- #371 (boundary, nit), second half: the release workflow drops `version:` on pnpm/action-setup
  and sets `package_json_file: frontend/package.json`.
