## Blocks to fix (verbatim from the reviews, all promoted)

1. **One home for the lifecycle tests** (`tests/lines.rs:196`): the supervisor's lifecycle (stop grace, ignore-stop
   kill, idle run, dropped receiver, late burst, orphan drain, stderr close) is tested only in
   `crates/pipe/tests/lines.rs`. Cut `crates/lsp-host/tests/run.rs` down to what `Host` adds: the project refusals, the
   program lookup, `stop_all`/`stop_every`, one Content-Length round trip, the 8 KiB stderr cut. Drop
   `--late-burst`/orphan/`close-stderr` machinery from `lsp-echo.rs` that no remaining test uses.
2. **One 64 MiB** (`frame.rs:106`, vision 2): `Frame::Dropped` carries a closed reason (e.g. `DropReason::TooLong |
   NotUtf8`); the log line is built in `run.rs` from `MAX_MESSAGE_BYTES / (1024 * 1024)` so its text stays exactly
   "…more than 64 MiB"; `HUGE_LINE_BYTES = yamt_pipe::MAX_MESSAGE_BYTES + 1` in `line-echo.rs`.
3. **No second copy of a line** (`frame.rs:111`): take the line by value — `Line::into_message(mut self) -> Vec<u8>`
   pops a trailing `\r` when not cut — then `String::from_utf8(line_bytes)` with no `to_vec()`; keep the
   `cut || len > MAX_MESSAGE_BYTES` check before it.
4. **The 8 KiB cut pinned here** (`frame.rs:288`): the test uses the literal — `"y".repeat(8 * 1024 + 5)` cut to
   `"y".repeat(8192)` — so it no longer depends on lsp-host's suite.
