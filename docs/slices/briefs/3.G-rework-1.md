## Findings (quoted, with the decision)

- #443 (correctness, should, RK5): "For a file deleted locally whose base is empty or absent …
  eol_source falls to the deleted local text, which is "". The file is then reported as Lf even when
  the kept remote is CRLF." **Decision:** line endings come from the first non-empty of base, local,
  remote; a `deleted_side.rs` case with an empty base and a CRLF kept remote expects CRLF.
- #445 (correctness, should): "%(refname:short) prints 'heads/<name>' when a tag of the same name exists
  … the header then shows 'heads/remote', and with several branches the MERGE_MSG name … no longer
  matches." **Decision:** `%(refname:lstrip=2)`; the gitio test adds a tag with the branch's name.
- #444 (correctness, should, RK19): "The expected short_id comes from conflict-repo's isolated git
  (GIT_CONFIG_GLOBAL=/dev/null), but the session's `log --format=%h` runs through gitio::git_command,
  which reads the user's config. On a machine with `core.abbrev` set globally, every Commit assertion
  fails." **Decision:** assert against the full id (short id is a prefix of it, ≥ 7 characters),
  subject and message exactly, in `remote_name.rs` and `merge_heads.rs`.
- #439 (boundary, should, RS7): "When MERGE_MSG cannot be read, the error becomes `Error::Io`, whose
  message is 'i/o error while running git: …'." **Decision:** a cause-named gitio error variant for a
  file read (path + source), used for MERGE_MSG.
- #440 (boundary, should, RS16): "`let remote_name = remote_name(&repo);` shadows the function … A Rust
  beginner reads that line as recursion." **Decision:** the free function becomes `read_remote_name`.
- #441 (nit, CP3): gitio's crate line names only stages and blobs — reword to include heads, refs and
  the merge message.
- #442 (nit): `merge_data` always sets `deleted: None` and `load` overrides it — give `merge_data` a
  `deleted: Option<Side>` parameter (cli passes `None`), drop the override.
- #446 (nit): the chmod-000 test fails as root — replace MERGE_MSG with a directory so the read fails
  for every user.
