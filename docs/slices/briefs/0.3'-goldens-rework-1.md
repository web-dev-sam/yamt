## Change

1. **The user's attributes and ignore files cannot leak in** (`scripts/golden-repo.sh` ~30). Even
   with `GIT_CONFIG_GLOBAL=/dev/null`, git reads `$XDG_CONFIG_HOME/git/attributes` and
   `~/.config/git/ignore` by default; a reviewer's probe with `* -merge` in XDG attributes produced
   "Cannot merge binary files" and no markers. Add `-c core.attributesFile=/dev/null
   -c core.excludesFile=/dev/null` next to `core.autocrlf=false`.
2. **A failed merge is not reported as a conflict** (`scripts/golden-repo.sh` ~56). Any non-zero
   `git merge` exit (also a fatal 128) is treated as the expected conflict. After the merge, require
   unmerged entries (`ls-files -u` non-empty) or `die "merge failed without leaving a conflict"`.
3. (nit) **Readable helper name** (~29): rename `g` to `repo_git`.
4. (nit) **State the real git floor** (~28): `GIT_CONFIG_GLOBAL` needs git ≥ 2.32. Check
   `git version` at the start and `die` with a clear message below 2.32; say the floor in
   `tests/golden/README.md`.
5. (nit) **Line count note** (`tests/golden/nuxt-island-test/README.md` ~6): `68/214/241 (remote has
   no final newline; wc -l prints 240)`.
