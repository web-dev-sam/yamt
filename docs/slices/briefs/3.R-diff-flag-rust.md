# Slice 3.R-diff-flag-rust — `yamt --diff` replaces `yamt --raw` in the shell

Board "Release 0.5.0" row 1a. Product rule: `docs/plan.md` §2 **#101** (read it whole). Owner's words (#1586):
"before you create the update, rename the raw flag to --diff". `--raw` was never released: clean cutover, no alias.
Beside you, row 1b renames the same flag in the window's fixture mode and the test tooling (it passes `--diff` to the
binary); the contract between you is only the flag text `--diff`.

## Contract

`Invocation` and every IPC type unchanged (no bindings change). The flag text is `--diff`.

## Change

1. Every `--raw` above reads `--diff`: the usage text (`yamt --diff`, "With --diff, …", the option line aligned as
   today), the usage error ("--diff compares pasted text and takes no --repo"), the lock and IPC messages ("another
   yamt --diff window is open (…)", "another yamt --diff window holds it"), doc comments, both AGENTS.md lines.
2. Identifiers and test names follow (`DIFF_WITH_REPO`, `diff`, `diff_opens_the_compare_window`, …); the tests keep
   proving the same rules with `--diff`.
3. `--raw` is not accepted anywhere (it falls to the unknown-argument path).

## Acceptance

- `cargo fmt --all --check`, `cargo clippy -p yamt-app -p yamt-compare --all-targets --features yamt-app/bindings -- -D
  warnings` (or the package names the workspace uses), `cargo test -p` for both packages: paste the tails.
- `grep -rn -- '--raw' src-tauri crates` → nothing (paste).
- `cargo build -p yamt-app` (debug), then: `target/debug/yamt --help` shows `yamt --diff` and the `--diff` line;
  `target/debug/yamt --diff --repo x; echo $?` → the usage error and 2 (or the exit code the parser uses for usage
  errors today; paste it); `target/debug/yamt --raw; echo $?` → the unknown-argument error, same code.
- Real app on a private display (`xvfb-run -a env -u WAYLAND_DISPLAY GDK_BACKEND=x11 XDG_DATA_HOME=<scratch> …`,
  never the owner's screen or data folder; `cargo tauri build --debug --no-bundle` first): `yamt --diff` opens the
  window titled "Compare — yamt"; a second `yamt --diff` with the same `XDG_DATA_HOME` prints "another yamt --diff
  window is open (…)" and exits 2 (paste). End the first with `kill` of its own PID, never `pkill`.
