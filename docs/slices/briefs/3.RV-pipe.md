## Contract (fixed; you may add, never change)

```rust
// crates/pipe/src/lib.rs (package yamt-pipe; #![forbid(unsafe_code)], #![warn(missing_docs)])
pub use crate::frame::{Framing, MAX_MESSAGE_BYTES};
pub use crate::program::{find, Found, ProgramFolders, ProgramFound, ProgramPlace};
pub use crate::run::{HostEvent, Running};

/// How messages are cut on the program's stdin and stdout.
pub enum Framing { ContentLength, Lines }          // Copy, Debug, PartialEq, Eq

impl Running {
    pub fn start(program: &Path, args: &[String], folder: &Path, framing: Framing,
                 events: Sender<HostEvent>) -> io::Result<Running>;
    pub fn send(&self, message: String);           // queued; framed by `framing`
    pub fn stop(&self);                            // closes stdin, 2 s, then kills; returns at once
    pub fn is_finished(&self) -> bool;
    pub fn wait(self);                             // reaps
}
pub fn find(root: &Path, project: &Path, program: &str, folders: &ProgramFolders) -> Result<Found, Vec<PathBuf>>;
pub struct Found { pub path: PathBuf, pub place: ProgramPlace }
```

`HostEvent`, `ProgramFolders`, `ProgramPlace`, `ProgramFound` keep their serde and specta shapes exactly (the
generated `bindings.ts` must not change). `yamt-lsp-host` re-exports `HostEvent`, `ProgramFolders`, `ProgramFound`,
`ProgramPlace` from `yamt-pipe` and keeps its own public API (`Host`, `RunId`, `ServerCommand`, `StartReply`,
`ServerContext`, `ProjectFile`) unchanged.

## Change

1. Move `run.rs`, `frame.rs`, `program.rs` (and the lookup's `plain_name`) into `crates/pipe/src/`; `Running` and
   `find` become public there; `Host` calls them with `Framing::ContentLength`.
2. `Framing::Lines`: write `message + "\n"`; read stdout one line at a time (a trailing `\r` is not part of the
   message), capped at `MAX_MESSAGE_BYTES`: a longer line is dropped with `Log { line: "yamt: dropped a message of
   more than 64 MiB" }` and reading goes on with the next line; a line that is not UTF-8 is dropped with a log line;
   empty lines are skipped.
3. `src/bin/line-echo.rs`: a test program that answers each line with the same line, plus `stderr <text>` (writes a
   stderr line), `exit <code>`, `huge` (writes one line over the cap, then `after`), `bytes` (writes a non-UTF-8 line,
   then `after`).
4. `arch-check.sh`: `yamt-pipe` depends on no `yamt-*` crate and never on tauri; `yamt-lsp-host` depends on
   `yamt-pipe` only among `yamt-*`.
