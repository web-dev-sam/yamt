## Findings to fix (quoted, with the decision)

- #381 (boundary, should): "Nothing regenerates or compares THIRD_PARTY_LICENSES.txt … Its `sort -u`
  also depends on the locale … a regeneration under C.UTF-8 on CI or on another machine would
  reorder the whole file." **Decision:** `export LC_ALL=C` at the top of the script; regenerate once
  and commit the result. Both release jobs (Linux and macOS), after the frontend install and before
  `ubuntu-versions`/tauri-action, run the script and `git diff --exit-code THIRD_PARTY_LICENSES.txt`,
  so a stale committed file fails the release with a message saying to run `just third-party-licenses`.
  Check the macOS runner has `jq` (it is on GitHub's macOS images; cite where you checked).
- #382 (correctness, should): "The Linux job appends the LGPL-3 text … but not the GNU GPL v3.
  LGPLv3 §4(b) requires the combined work to carry 'a copy of the GNU GPL and this license
  document'." **Decision:** append `GPL-3` from `/usr/share/common-licenses/` too; the function
  holding the texts gets a name that says GNU licence texts.
- #388 (correctness, should): "`install -m755 … ~/.local/bin/yamt` errors when ~/.local/bin does not
  exist, and on fresh Apple Silicon macOS /usr/local/bin is absent." **Decision:** `install -Dm755
  yamt_0.1.0_amd64.AppImage ~/.local/bin/yamt`; `sudo mkdir -p /usr/local/bin && sudo ln -s
  /Applications/yamt.app/Contents/MacOS/yamt /usr/local/bin/yamt`.
- #383 + #389 (boundary and correctness, should): "AppImageLauncher catches every run of
  `~/.local/bin/yamt` through binfmt: 'Integrate and run' moves the file to ~/Applications, so `yamt`
  is gone from PATH, and 'Run once' asks again on every start. The 'asks once' sentence is wrong."
  **Decision:** the README gives a working path for AppImageLauncher users, verified on this machine
  (AppImageLauncher is installed here): integrate without a dialog (`ail-cli integrate <file>`, if
  this machine's AppImageLauncher has it), then link the integrated file (whatever name it got) to
  `~/.local/bin/yamt`, and show that `yamt` started from a terminal in a conflict repository opens
  the window _without_ `APPIMAGELAUNCHER_DISABLE`. Undo every trace afterwards (`ail-cli
  unintegrate`, the link, the desktop entry, the moved file) and list what you removed. If
  `ail-cli` is missing or the linked file still triggers a dialog, say so and write the README
  line you could verify instead (e.g. `APPIMAGELAUNCHER_DISABLE=1` in an alias). Never click
  dialogs on the owner's screens; if one opens, close it with a KWin script and report it.
- #387 (correctness, should): "`current_exe()` on Linux is the kernel-resolved /proc/self/exe path,
  but the runtime builds APPDIR from `$TMPDIR/.mount_*` without resolving it. With a TMPDIR that is
  relative or goes through a symlink, a real AppImage counts as outside." **Decision:** in
  `repo_from_start_dir`, canonicalize APPDIR (keep the raw value if that fails) before
  `is_inside_appimage`; the pure function and its tests stay.
- #391 (correctness, nit): "The `Some("")` assertion passes without the `is_absolute` guard …"
  **Decision:** drop that assertion (the relative-OWD case covers #376) or rename the test to match.
- #384 (boundary, should): "`record_close_request` returns the page-gone bool, but its name says
  only that it records … reads as 'if the request was recorded, destroy the window'."
  **Decision:** it returns a two-variant enum (`CloseRequest::PageGone` / `CloseRequest::AskPage` or
  similar), matched in `on_close_request`.
- #385 (boundary, nit): "The grace boundary is written twice … must stay complementary by hand."
  **Decision:** compute how long the earlier request has been unanswered once and derive both "gone"
  and "keep the earlier time" from it.
- #390 (correctness, nit): "`PAGE_PING` is both the script and the expected answer …" **Decision:**
  `const PAGE_ANSWER: &str = "true"` next to `PAGE_PING`; `answered` compares against it; the test
  asserts the literal `"true"`.
- #386 (boundary, nit): "The summary hard-codes the generated counts … 'only its MIT text is quoted'
  is also inaccurate." **Decision:** drop the counts; say "when a crate offers MIT as one choice and
  ships an MIT file, its other licence files are left out".
