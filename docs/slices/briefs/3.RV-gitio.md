# Slice 3.RV-gitio — `yamt-gitio` reads a commit range: changed files, merge base, common git dir, blob sizes

Board "Review a commit range" row 3. Product rules: `docs/plan.md` §2 **#103**, **#104**, **#105** — read them in full.
Request: `docs/slices/request-review-range.md` A rules 1–5. Design: `.omp/run/notes/RangeDesign.md` option A §1 (facts),
§2 (git reads), §7 (what the listing must carry for the special files), §10 (the `crates/gitio/tests/diff.rs` list).
Row 5 (the crate `yamt-range`) builds on this API; nothing else uses it yet.

Facts (given, from the design's sources):

- `git diff-tree --raw --numstat -z` prints all raw records first, then all numstat records; numstat prints `-\t-\t`
  for a binary pair; with `-z` a renamed pair's numstat is `added\tremoved\t\0old\0new\0` (git `diff.c`
  `show_numstat`). Match numstat records to raw records **by destination path**, never by position; a raw record with
  no numstat record is `Numstat::Missing`.
- `diff-tree` is plumbing: `builtin/diff-tree.c:127` reads only `git_diff_basic_config`, so `diff.renames`,
  `diff.noprefix`, `diff.relative`, `diff.external`, `diff.orderfile`, `diff.ignoresubmodules`, `diff.algorithm` never
  apply; it runs no textconv and no external diff. `submodule.*` is basic config, hence `--ignore-submodules=none`.
  `diff.renameLimit` still applies: above it git skips inexact renames and warns on stderr; the run still succeeds.
- `Repo::commit_named` (`crates/gitio/src/repo.rs:40`) already runs `rev-parse --verify --quiet <name>^{commit}`;
  `Repo::commit_summary` (`names.rs:54`) gives a short id and the subject; `BlobReader` (`blob.rs`, `Repo::blob_reader`)
  runs `cat-file --batch`. Commands go through `Repo::command(Access, args)` (`repo.rs:182`) with the crate's deadline.
- Test repositories: `yamt-conflict-repo` (dev-dependency) `diverged_repo`, `git_ok(dir, args)` (`crates/conflict-repo/
  src/lib.rs:97,159`), with user and system git config isolated (RK19).

## Contract (fixed; you may add, never change)

```rust
// crates/gitio/src/diff.rs (re-exported from lib.rs)
pub struct TreeSide { pub path: PathBuf, pub mode: u32, pub oid: Oid }
pub enum Changed {
    Added { new: TreeSide },
    Deleted { old: TreeSide },
    Modified { old: TreeSide, new: TreeSide },   // raw M and T (a kind change: the modes say which)
    Renamed { old: TreeSide, new: TreeSide },    // raw R<score>
}
pub enum Numstat { Lines { added: u32, removed: u32 }, Binary, Missing }
pub struct ChangedFile { pub change: Changed, pub numstat: Numstat }

impl Repo {
    /// `git diff-tree -r -z --raw --numstat --no-abbrev -M --diff-algorithm=histogram --ignore-submodules=none <old> <new>`
    pub fn changed_files(&self, old: &Oid, new: &Oid) -> Result<Vec<ChangedFile>>;
    /// `git merge-base <a> <b>`: the first base when there are several (as `git diff a...b`); exit 1 → None
    pub fn merge_base(&self, a: &Oid, b: &Oid) -> Result<Option<Oid>>;
    /// `git rev-parse --path-format=absolute --git-common-dir`: one identity for every worktree of a repository
    pub fn common_dir(&self) -> Result<PathBuf>;
}
// crates/gitio/src/blob.rs
impl Repo {
    /// one `git cat-file --batch-check` run over all ids; answers in input order; None = missing; a gitlink id is never asked
    pub fn blob_sizes(&self, oids: &[Oid]) -> Result<Vec<Option<u64>>>;
}
```

Derives as the crate's other public types (`Debug`, `Clone`, `PartialEq`, `Eq` where they fit). Raw status `C`, `U`,
`X` (and anything else) → the crate's `UnexpectedOutput` error. `-` at the start of a side never reaches git (callers
pass resolved `Oid`s only).

## Change

1. `diff.rs`: the run and a pure parser of its `-z` output (raw records, then numstat records), unit-tested on byte
   strings: a rename record, numstat records out of raw order matched by path, a binary pair, a path holding a tab, a
   newline, a space and non-UTF-8 bytes.
2. `repo.rs`: `merge_base`, `common_dir`. `blob.rs`: `blob_sizes` (one process, every id on stdin, `<oid> missing`
   → None).
3. Integration tests in `crates/gitio/tests/diff.rs` against real temp repositories (the design's §10 list):
   `added_modified_deleted_files_are_listed_with_git_s_counts`,
   `a_renamed_file_lists_both_paths_and_counts_only_its_edits`, `a_binary_file_is_listed_without_counts`,
   `a_mode_only_change_lists_both_modes_and_one_blob_id`, `a_submodule_commit_change_is_listed_as_a_gitlink`
   (`update-index --cacheinfo 160000,…`), `a_file_replaced_by_a_link_is_one_modified_entry_with_both_modes` (unix),
   `the_users_diff_config_does_not_change_the_list` (repository config `diff.relative`, `diff.orderFile`,
   `diff.renames=false`, `diff.algorithm=minimal`, `diff.external`, `diff.ignoreSubmodules=all`, plus
   `GIT_EXTERNAL_DIFF` and `GIT_DIFF_OPTS` in the environment), `paths_with_spaces_newlines_and_non_utf8_bytes_round_trip`
   (unix for the non-UTF-8 name), `merge_base_is_the_fork_point_and_none_for_unrelated_histories`,
   `blob_sizes_answer_in_order_and_missing_as_none`, `common_dir_is_the_same_from_a_linked_worktree`.
