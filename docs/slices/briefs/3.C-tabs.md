## Contract (fixed; you may add, never change)

```rust
// crates/compare/src/lib.rs (package yamt-compare; #![forbid(unsafe_code)], #![warn(missing_docs)])
#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash, Serialize, Deserialize, Type)]
pub struct TabId(pub u32);
#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize, Type)]
#[serde(rename_all = "lowercase")]
pub enum Column { Left, Right }
#[derive(Clone, Copy, Debug, PartialEq, Eq, PartialOrd, Ord, Serialize, Deserialize, Type)]
pub struct ColumnVersion(pub u32);
#[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Type)]
pub struct ColumnVersions { pub left: ColumnVersion, pub right: ColumnVersion }
#[derive(Clone, Debug, PartialEq, Eq, Serialize, Deserialize, Type)]
#[serde(tag = "kind", rename_all = "camelCase")]
pub enum TabLanguage { Auto, Picked { name: String } }        // the name is opaque here (a window language name)
#[derive(Clone, Debug, PartialEq, Eq, Serialize, Type)]
pub struct TabEntry { pub id: TabId, pub name: String, pub language: TabLanguage, pub holds_text: bool }
#[derive(Clone, Debug, PartialEq, Eq, Serialize, Type)]
pub struct TabList { pub tabs: Vec<TabEntry>, pub shown: TabId }  // in the stored order
#[derive(Clone, Debug, PartialEq, Eq, Serialize, Type)]
pub struct CompareStart { pub list: TabList, pub column_limit: u32 }
#[derive(Clone, Debug, PartialEq, Eq, Serialize, Type)]
pub struct Comparison { pub versions: ColumnVersions, pub differences: Vec<yamt_merge_core::Difference> }
#[derive(Clone, Debug, PartialEq, Eq, Serialize, Type)]
pub struct TabTexts { pub left: String, pub right: String, pub comparison: Comparison }
pub const MAX_COLUMN_BYTES: u32 = 8 * 1024 * 1024;

#[derive(Debug, thiserror::Error)]
pub enum Error {
    Locked { path: PathBuf },                       // another process holds the lock file
    Broken { path: PathBuf, message: String },      // tabs.json unreadable as format 1; message carries line and column
    NewerFormat { path: PathBuf, format: u32 },
    ReadFailed { path: PathBuf, message: String },  // also a column file that is not UTF-8
    WriteFailed { path: PathBuf, message: String },
    UnknownTab { tab: TabId },
    TooLarge { bytes: usize },                      // a column over MAX_COLUMN_BYTES, sent or on disk
}

/// One tab's two texts and their versions, shared with the store (no copy), so the diff runs outside its lock.
pub struct LoadedTab { /* private: Arc<str> per column, ColumnVersions */ }

pub struct TabStore { /* private */ }
impl TabStore {
    pub fn open(dir: &Path) -> Result<TabStore, Error>;   // creates dir, takes the lock, reads or creates tabs.json, removes orphan files
    pub fn start(&self) -> CompareStart;
    pub fn load_tab(&mut self, tab: TabId) -> Result<LoadedTab, Error>;
    pub fn set_column(&mut self, tab: TabId, column: Column, text: String, version: ColumnVersion) -> Result<LoadedTab, Error>;
    pub fn add_tab(&mut self) -> Result<TabList, Error>;
    pub fn close_tab(&mut self, tab: TabId) -> Result<TabList, Error>;
    pub fn rename_tab(&mut self, tab: TabId, name: &str) -> Result<TabList, Error>;
    pub fn set_language(&mut self, tab: TabId, language: TabLanguage) -> Result<TabList, Error>;
    pub fn show_tab(&mut self, tab: TabId) -> Result<TabList, Error>;
}
pub fn comparison(loaded: &LoadedTab) -> Comparison;    // yamt_merge_core::compare on the two texts + their versions
pub fn tab_texts(loaded: &LoadedTab) -> TabTexts;       // the two texts and comparison(loaded)
```

## Behaviour

1. **Files** in `dir`: `tabs.json` = `{ "format": 1, "shown": <id>, "nextId": <id>, "tabs": [{ "id", "number", "name",
   "language": { "kind": "auto" } | { "kind": "picked", "name" } }] }`; `<id>-left.txt` / `<id>-right.txt` plain UTF-8,
   a missing file = an empty column; `lock`. Every write is a temp file in `dir` + rename. `tabs.json` is rewritten only
   on add, close, rename, language and shown; a column file only by `set_column` for that column. No other file is
   rewritten.
2. **Open**: `try_lock` on `lock` (kept for the store's life; the OS releases it on any exit, also `kill -9`) — held
   elsewhere → `Locked`. No `tabs.json` → one tab `{ id: 1, number: 1, name: "Compare 1", language: Auto }`, shown,
   written at once. A `tabs.json` that does not parse as format 1, has no tabs, repeats an id or names a `shown` not in
   it → `Broken` (serde's message with line and column where it has one); `format` > 1 → `NewerFormat`; in all three
   cases nothing in `dir` is written or removed. Then column files and temp files whose id is not in the index are
   removed; other files are left alone. `holds_text` of an unloaded tab = either column file non-empty (metadata only,
   no read).
3. **Versions** live in memory only: both start at 0 per tab at open; `load_tab` reads the two files once (later calls
   return the same texts without reading), non-UTF-8 → `ReadFailed`, over the limit → `TooLarge`. `set_column` with a
   version not higher than the stored one stores nothing and returns the stored texts and versions; otherwise it
   checks the limit (`TooLarge`, nothing stored), writes that column's file, then updates the text and version. A
   failed write changes nothing in memory. `set_column` on a tab never loaded loads it first.
4. **Tabs**: a new tab gets `number` = 1 + the highest number among existing tabs, name `Compare <number>`, id =
   `nextId` (ids never repeat), is appended last and shown. `close_tab` writes the index without the tab first, then
   deletes its files; the shown tab closed → the next one is shown, else the previous; the last tab closed → a new
   "Compare 1" (new id). `rename_tab` trims the name; an empty result keeps the old name (no error). `UnknownTab` for
   any id not in the index.
5. **No text is copied while the store is borrowed**: columns are `Arc<str>`, `LoadedTab` holds clones of the `Arc`s;
   `comparison`/`tab_texts` run on a `LoadedTab` after the caller released the store.
6. **Arch-check**: `yamt-compare` may depend on `yamt-merge-core` only among `yamt-*`, never on `tauri`; `yamt-app` may
   also depend on `yamt-compare`.

## Acceptance

`crates/compare/tests/` (real temp dirs, each test naming the bug it catches): first open creates "Compare 1" and its
`tabs.json`; numbers follow the rule (close "Compare 2" of three → the next is "Compare 4"; close all but "Compare 1" →
"Compare 2"); closing the last tab leaves a fresh "Compare 1"; closing the shown tab shows the next, the last shown tab
the previous; `set_column` rewrites only that column's file (the other column file and `tabs.json` keep their modified
time and bytes); a stale version is ignored and the reply carries the stored versions; a restart (drop, open again)
reads back the order, names, languages, shown tab and both texts; broken JSON → `Broken` with a line, the bytes on disk
unchanged and no new file; format 2 → `NewerFormat`; a second `open` of the same dir while the first lives → `Locked`,
and after the first is dropped it opens; a column over the limit → `TooLarge`, nothing written; a missing column file
reads as empty; orphan column files are removed, a foreign file is kept; a non-UTF-8 column file → `ReadFailed` at
`load_tab` and is never rewritten by another call; `holds_text` before and after a load; `rename_tab` with spaces only
keeps the name; `comparison` equals `yamt_merge_core::compare` on the texts. Your tests kill the mutants on your lines
(the orchestrator runs `just mutants` after your patch, SP5).
