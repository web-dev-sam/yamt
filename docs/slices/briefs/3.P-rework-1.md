## Findings (quoted, with the decision)

- #491 (boundary, should): "geometry.ts was a single vocabulary (where each chunk sits in each pane,
  in document px), but now also holds what each strip shows: crossesStrip, gapArrows …, bandPaints
  …, Arrow and BandPaint. These were moved only so strips.ts fits under 300 lines." **Decision:** a
  new `editor/internal/gap.ts` — what a strip shows — holds `crossesStrip`, `gapArrows`,
  `bandPaints`, `Arrow`, `BandPaint`; `geometry.ts` goes back to chunk positions. Imports in
  `strips.ts`, `drag.ts` and the tests follow (clean cutover); tests of those helpers move to
  `gap.test.ts`. The orchestrator lists the file in the project map.
- #492 (boundary, should): "`Arrow.top` means two different things: gapArrows returns
  document-relative tops (drag.ts:41 relies on that), while GapStrip.measure re-emits the same
  `Arrow` type with strip-relative tops." **Decision:** `Arrow` stays in document space; a placed
  row carries its own strip-space field (e.g. `{ arrow, y }`), used for the transform and the
  `crossesStrip` filter.
- #493 (boundary, should) + #500 (correctness, should): the `#anchors` memo in `ScrollSync` is keyed
  on rows identity but also captures `ends(views)`; it is right only because the controller drops its
  rows cache on every `geometryChanged`, a contract stated in another file. **Decision:** one cache.
  The controller's cache holds rows and their anchors together (anchors may be filled lazily from the
  same rows), dropped by `rowsChanged`; `ScrollSync.sync` takes the anchors; `#anchors`/`#anchorsOf`
  go.
- #494 (boundary, should): the `MergeView.vue` comment cites "(slice 3.P)" for a measurement that
  lives only in a run report. **Decision:** the decision is now plan §2 #51; the comment cites
  "(plan §2 #51)" and keeps only what a reader needs (why the wrapper and `will-change` exist).
- #499 (correctness, should): "`bandPaints` is a new pure exported helper but has no test …
  Swapping `shifts.left`/`shifts.right`, or testing only `onLeft`, would pass all 333 tests."
  **Decision:** `gap.test.ts` cases on a fixture's rows: local vs remote pick the right span pair with
  their own shift (compare `d` with `bandPath` of the expected band); a band whose left edge is above
  the strip while its right edge is inside is kept; a band 1 px outside is dropped.
- #497 (boundary, nit): `look` is a space-joined equality key. **Decision:** compare the row's stored
  `mode` and button positions in a small predicate named for what it decides (e.g. `sameShape`).
- #498 (boundary, nit): the read-only case is checked twice (`measure` and `paint`). **Decision:**
  check it once.
- #502 (correctness, nit): `#rowsCache`/`#rows()` hand out a mutable `ChunkRow[]` shared across
  frames. **Decision:** `readonly ChunkRow[]` (and readonly anchors).
