# Slice 3.Z-ipc — the window's IPC side of Save: `waiting` on every chunk, `saveFile`

Board "Language servers and saving" row 3b. Product rules: `docs/plan.md` §2 **#65**, **#69**. The Rust half is
committed (`cf9bbe1`, notes `.omp/run/notes/SaveRust.md`): `ipc/bindings.ts` now has `MergeChunk.waiting: Waiting`
(`{ kind: "SideLines" } | { kind: "Markers"; open: string; between: string[]; close: string } | { kind: "AsShown" }`)
and `commands.saveFile(path, text, diskVersion) -> WriteReply`; the fixtures are regenerated with `waiting`. Since
then `pnpm -C frontend typecheck` fails in `ipc/fixture.ts` (the valibot schema lacks `waiting`) and
`ipc/tauri.test.ts`. This slice makes the IPC layer carry both, so the tree is green again and the Save build later
only consumes them.

## Target

Owned: `frontend/src/ipc/fixture.ts`, `fixture.test.ts`, `domain.ts`, `ChunkSource.ts`, `tauri.ts`, `tauri.test.ts`.

Read-only: everything else, in particular `ipc/index.ts` (another build owns it right now: if consumers would need a
new export from it, report the exact line in `deviations_from_brief` instead), `ipc/bindings.ts` (generated),
`editor/**`, `ui/**`.

Non-goals: the Save key, the file builder, the dot, any `ui/` or `editor/` change; Rust.

## Contract (fixed)

```ts
// domain.ts: the domain Chunk carries waiting unchanged (no brand); toChunk copies it
Chunk.waiting: Generated.Waiting
// ChunkSource.ts
saveFile(request: { readonly path: string; readonly text: string; readonly diskVersion: DiskVersion }): Promise<SourceResult<WriteReply>>;
```

## Change

1. `fixture.ts`: a `WAITING` valibot schema (`v.variant("kind", …)`) `satisfies SchemaOf<Generated.Waiting>`, added to
   `MERGE_CHUNK`; `saveFile` in the fixture source: logs `fixture.save` with the path and the text's length and line
   count, replies `Written` with the current files, and does **not** mark the file finished (unlike `finishFile`).
2. `domain.ts`: `Chunk` gains `waiting`; `toChunk` copies it.
3. `ChunkSource.ts` + `tauri.ts`: `saveFile` mapped onto `commands.saveFile`, the same way `finishFile` is.
4. Tests: `fixture.test.ts` — a golden fixture parses with its `waiting` values (a conflict's `Markers` lines start
   with `<<<<<<<`, `=======`, `>>>>>>>`), a malformed `waiting` is rejected, `saveFile` replies `Written` and leaves the
   file unresolved; `tauri.test.ts` — the test chunk gains `waiting`, `saveFile` passes its three arguments.
