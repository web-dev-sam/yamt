What the window does now:

- yamt remembers each conflicted file's disk content and looks on window focus and before each of
  its writes;
- a file with no markers left, or deleted, is staged and marked resolved, with a notice;
- markers left → the middle pane shows the disk text with one conflict per open block;
- a file already changed before start is treated the same way;
- unsaved edits of a changed file are dropped, and the notice says so.
