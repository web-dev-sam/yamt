## Change

1. **Error derives like every other crate** (`src/lib.rs` ~24, RS7). Replace the hand-written
   `Display` / `From` / empty `impl std::error::Error` with `#[derive(Debug, thiserror::Error)]`,
   `#[error("…")]` per variant, `#[from]` on the session and JSON errors, `#[source]` on the I/O
   errors so the cause chain survives. Messages and exit codes unchanged (tests pin them).
2. **Non-UTF-8 arguments are a usage error, not a panic** (`src/main.rs` ~4, RS8).
   `std::env::args()` panics on a non-Unicode argument. Read `args_os()` and turn an
   `OsString` that is not UTF-8 into a usage error (`yamt-cli: …`, exit 2). Test it (on Linux an
   argument from `OsStr::from_bytes(b"\xff")`).
3. **RK13's dangerous direction is bounded** (`tests/merge_file.rs` ~224). The deterministic
   sample prints `only_git_conflicts` (yamt clean, git conflicting) but never limits it. Assert it
   stays at or under a named ceiling (`MAX_ONLY_GIT_CONFLICT_PERCENT`, e.g. 1; 0 of 512 today).
4. **`golden run` compares bytes, provably** (`tests/commands.rs` ~133). Add a case whose
   expected.json is the same JSON with `\r\n` line endings → exit 1 with the line-ending hint;
   and one with a missing final newline → exit 1 with a `trailing newline differs` hint (see 7).
5. **Name says which side** (`src/golden.rs` ~72): rename `expected_json(case)` to
   `computed_json(case)` (it computes; `expected` is the file).
6. (nit) **Shared file helpers live with the other shared I/O** (`src/case.rs` ~82): move
   `read_text` / `read_error` to `lib.rs` beside `print` / `print_lines`; `classify` imports them
   from `crate::`.
7. (nit) **Trailing-newline hint** (`src/golden.rs` ~109): before the line loop, if exactly one
   side ends with `\n`, report `trailing newline differs` instead of the line-ending hint.
8. (nit) **One spelling of the file name** (`src/golden.rs` ~83): build the hint from
   `EXPECTED_FILE` (make it `pub(crate)`).
