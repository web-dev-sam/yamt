## Blocks to fix (verbatim from review)

1. **#1313** `read_if_present`, a general "read a git-dir file, missing = None" helper, lives in the operation module,
   and `repo.rs:8` imports it from there. The base `Repo` module now depends on the stop reader for a filesystem
   primitive, and the next reader of a state file (#90's `MERGE_RR`) will import it from `operation`. `exists` (line 310) repeats the same `try_exists` → `ReadFailed` mapping as `rebase_in_progress` (repo.rs:104). **Fix:** move
   `read_if_present` and `exists` into `repo.rs` next to `git_path`/`git_paths` as `pub(crate)` items, and import them
   into `operation.rs` (and use `exists` in `rebase_in_progress`).
2. **#1314** `git_paths` copies `git_path`'s rule (repo.rs:124): `rev-parse --git-path`, `without_final_newline`,
   `root.join(path_from_git(..))`. **Fix:** write `git_path(name)` as the single element of `git_paths(&[name])`.
3. **#1319** `sequence_progress` hands `sequencer/head` straight to `rev-list --count <head>..HEAD`. If that oid is
   well-formed hex but not a commit (a pick range on an unborn branch saves the zero oid), `stop()` returns
   `Err(GitFailed)` instead of `progress: None`, failing every list. **Fix:** resolve the start through
   `commit_named` first; `Ok(None)` when it is not a commit; count from the resolved oid.
4. **#1320** Sequence progress is attached to whichever head ref exists, without checking that the sequencer runs the
   same kind: a single `git revert Y` stopped inside a stopped pick range reads the range's count; `cherry-pick -n A..B`
   makes no commits, so its step-2 stop reads 1/2 instead of 2/3. **Fix:** attach `progress` only when
   `first_command(todo)` matches the operation (pick/p for `CherryPick`, revert for `Revert`); `None` when
   `sequencer/opts` sets `no-commit = true`.
5. **#1322** `edit_todo_dropping_a_later_step_keeps_the_id` runs on `Run::Rebase`, where dropping a pick changes
   nothing in the `Stop`, so it would pass even if `id()` were the whole `Stop`. **Fix:** use `Run::RebaseInteractive`,
   drop the `reword` line, assert `editor_steps_ahead` goes from true to false, then that the ids are equal.

Also update the `Stop::id` doc line: Continue, Abort and the moved-on check compare `id()` (#1311).
