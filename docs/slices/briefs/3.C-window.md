## Behaviour

1. **Two roots** (`main.ts`, two function declarations): `data-window="compare"` (app) or `?raw` (fixture) →
   `createCompareStore(source, startTheme)`, `startUp()`, `CompareApp` mounted; never builds `LanguageServers`, never
   creates the merge store. Otherwise the merge start exactly as today.
2. **Fence PM7** (`fences.ts` + its failing-path test): `ui/Compare*.vue`, `ui/compare*.ts`, `ui/TabList.vue`,
   `ui/LanguagePicker.vue`, `ui/useCompareController.ts` never import `ui/store.ts`, `ui/App.vue` or `lsp/`.
3. **`CompareApp.vue`**: the tab panel in the file list's place (hidden by Ctrl/Cmd+B through `fileListKey` on
   `fileListShown`), the shown tab's view in the grid cell, `NoticeBar` with the store's rows, `ProblemBar`,
   `QuestionDialog`, `SettingsView` (no slot: Theme, Antialiasing, Keymap, the settings file) when `screen` is
   settings; settings re-read on window focus; `onWindowClose(async () => { await flushAll(); return true; })`, no
   question.
4. **`TabList.vue`**: header "Tabs" with an icon-only "+" (title "New tab"); one row per tab in order: name and
   `languageLabel` (muted), the shown tab highlighted as the shown file is; a click shows it; an × on the hovered row
   (title "Close tab") calls `closeTab`; a double-click on the name renames inline (Enter keeps, Escape cancels, empty
   keeps the old name, blur keeps); width, drag and dots as the file list (`createFileListWidth`'s key, so both windows
   share one width).
5. **`CompareView.vue`** (one per visited tab, mounted on first show, hidden when not shown, unmounted on close):
   toolbar — Format (disabled with a hover text naming JSON and XML when `formatLanguage()` is null), the
   `LanguagePicker`, previous/next change arrows (`moveToChange`), `SettingsButton`; headers "Left" and "Right"; two
   hosts with the strip between them (`compareColumns()`); the controller through `useCompareController`.
6. **`useCompareController.ts`**: builds the controller once the hosts exist and `loadTab` answered; `settled` →
   `saveColumn` per column → `showComparison` (a dropped reply needs nothing); `detected` → `setDetected`; `refused` →
   `refused`; `track(tab, { unsent: settleNow, holdsText })` and untrack on scope dispose; watches preferences and the
   tab's language; Format → `reportFormat` with each failed column as `{ column, language, message, line }`; `destroy`
   on scope dispose.
7. **`LanguagePicker.vue`**: a drop-down button reading `languageLabel`; items "Auto" then `languageNames()`, the
   current one checked, keyboard through `menuKeys`; a pick calls `setLanguage`.
8. **app-session**: `--raw` starts the app with `--raw` and no `--repo` (fixture mode: `?raw`), so later runs can drive
   the compare window.

## Acceptance

- Node tests: `fences.test.ts` (PM7's failing path: a compare file importing `./store` is reported); `useCompareController`
  only where a rule lives there (the Format failure mapping, the settle → save → show order), never wiring;
  `paneSplit.test.ts` for `compareColumns`.
- WebKit (`just app-session start-fixture` with `?raw` / `?raw=json-payload`, MiniBrowser through `just webdriver`):
  the compare page with one tab; `?raw=json-payload` shows bands, word marks and removal bars in both columns and the
  strip; "+" adds "Compare 2" and shows it; switching keeps each tab's texts and scroll; rename (Enter, Escape, empty);
  close of a tab with text asks, of an empty one does not; Ctrl/Cmd+B hides the panel; the language drop-down shows
  "Auto · JSON" on the JSON case and picking TypeScript highlights both columns; Format on two differently laid-out
  JSON texts leaves no bands; invalid JSON in one column shows its notice; the gear opens the settings view without the
  language-server section; dark and light screenshots.
- Real app (`just app-session` with `--raw`, a fresh home): typing in both columns updates the differences after the
  pause; quit and start again → the same tabs, names, texts, languages and shown tab; `kill -9` a second after typing
  → the text is back; a second `yamt --raw` exits 2; the merge window (`scripts/conflict-repo.sh`) unchanged (one file
  opens, settings view with its language-server section).
- Commands: `pnpm -C frontend typecheck`, `test`, `lint`, `unused` (now every new export has its importer), `fmt:check`,
  `just sfc-order`.
