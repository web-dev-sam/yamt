## Behaviour

1. **One writer per fact**: `tabs`/`shown` change only from `TabList`/`CompareStart` replies (no optimistic edits);
   `detected` only through `setDetected`; notices only through `reportFormat`/`refused` and `dismissNotice`.
2. **Close**: a tab whose tracked handle (or, untracked, its entry) holds text asks `closeTab { name }`; Yes closes,
   No/dismissed keeps it; an empty tab closes at once; before closing, the tab's unsent columns are not sent (its
   text is going away). Untracks it.
3. **Flush**: `flushAll` sends every tracked tab's `unsent()` columns with `setColumn` and resolves when all replied
   (failures logged and shown, never thrown).
4. **Notices** (words only in `compareText.ts`): a Format failure per column, "Compare 2, left: not valid JSON (line 3):
   Expected ',' or '}'" (the language from the failure); a refused edit "Compare 2, right: not pasted — a column holds
   up to 8 MiB" (the limit from `columnLimit`, written as MiB); a new notice for the same tab and column replaces the
   old one; keys stable per tab and column.
5. **Problems**: every failed reply through `report`/`attempt` with the new actions; `UnknownTab` after a close in
   another call refreshes nothing silently — it is shown as the problem with its words.
6. **Settings**: the store's settings part is `settingsActions` over its own state, registered with
   `registerSettingsStore` at creation, `openSettings`/`closeSettings` switch `screen`.
