# Slice 0.1' — rework round 1 (gitio)

Same Target, Contract, Non-goals, Skills and Report as `0.1'-gitio.md`. Both reviews passed;

else. The tree already contains the first round (applied, uncommitted); you start from it.

## Change

1. **Timeout covers the output pipes too** (`src/run.rs` ~61, RK15). Today the deadline only
   covers git's own exit; stdout/stderr are joined afterwards with no limit. `checkout -m` runs
   the user's post-checkout hook; a background process it starts can keep stderr open, and
   `checkout_merge` then blocks forever. Make the reader threads deliver their bytes over an
   `std::sync::mpsc` channel and receive with `recv_timeout(deadline - now)`; past the shared
   deadline → `Error::Timeout`. Extend the in-file timeout test (or add one) so it would fail if
   the pipe wait were unbounded — e.g. a `!` alias that backgrounds `sleep` holding stderr while
   git itself exits at once.
2. **Non-blob read keeps the reader usable** (`src/blob.rs` ~38). Extend test 5: read the HEAD
   commit oid (fixture `git rev-parse HEAD` → `Oid::parse`), assert
   `UnexpectedOutput { command: "cat-file", .. }`, then assert the next `read` of the Base oid
   still returns BASE.
3. **`git` path is absolute** (`src/repo.rs` ~76, RS15). `find_git_on_path` accepts relative
   `PATH` entries (empty → `git`, `bin` → `bin/git`), which `Command` then resolves against the
   repo root. Skip entries where `!dir.is_absolute()`.
4. **Readable removal-record loop** (`src/entry.rs` ~123, vision 1). Replace `enumerate()` +
   `if index == 0` with an explicit "first entry of each path" list, then per path: one removal
   record, then that path's stage records.
5. **No `Option::zip` for the stdin writer** (`src/run.rs` ~48, vision 1). Use
   `if let (Some(mut pipe), Some(bytes)) = (child.stdin.take(), stdin) { … } else { None }`.
6. **Comments** (`skill://comment-policy`). Delete doc comments that restate the name, fields
   or the code: `blob.rs:9`, `repo.rs:14`, `entry.rs:10`, `entry.rs:36`, `entry.rs:63`,
   `entry.rs:111`, `run.rs:12`, `run.rs:43`. Replace the `run.rs:108` comment explaining what
   `None` means with a named private enum (e.g. `Waited { Exited(ExitStatus), TimedOut }`).
   Keep `entry.rs:75` as a `//` line citing `git-ls-files(1)` `-z` output (external fact).
7. **Timeout test runs on macOS** (`src/run.rs` ~133). The reap check reads
   `/proc/self/task/*/children`, which macOS lacks. Put that helper and its assertion under
   `#[cfg(target_os = "linux")]`; the `Timeout` and elapsed-time assertions run everywhere.
8. (nit) **Readable `GitFailed` message** (`src/lib.rs` ~17, `src/run.rs` ~67). Store
   `stderr.trim_end()`; render the status as `exit status N`, or `killed by signal` when there is
   no code — no `Some(..)` in user-facing text.
9. (nit) **One spelling per subcommand** (`src/entry.rs` ~71, `blob.rs` ~7, `repo.rs` ~23/27/41/46,
   vision 2). The error label and the argv use the same `const` (or the label moves next to
   the argv), so they cannot drift.
