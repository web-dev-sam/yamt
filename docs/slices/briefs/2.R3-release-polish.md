## Changes (quoted, with the decision)

- #392 + #396 (boundary should, correctness nit): "The `install -Dm755 … ~/.local/bin/yamt` block is
  shown first and without any condition … A reader who has already run the first block then gets
  `ln: failed to create symbolic link '~/.local/bin/yamt': File exists`." **Decision:** label the two
  AppImage blocks by who they are for ("Without AppImageLauncher:" / "With AppImageLauncher:") and
  use `ln -sf` in the second.
- #394 (correctness, should): "`only_the_ping_answer_counts_as_answered` checks only "true" and "",
  so `answered` written as `!result.is_empty()` still passes." **Decision:** add
  `assert!(!answered("false"))` and `assert!(!answered("null"))`.
- #395 (correctness, nit): "`generate` writes through `mktemp` (mode 0600) and then `mv`s the file
  over THIRD_PARTY_LICENSES.txt … the macOS .app and the AppImage ship it as 0600." **Decision:**
  `chmod 644 "$tmp"` before the `mv`. Do not regenerate or edit `THIRD_PARTY_LICENSES.txt` (content
  unchanged; git does not track 0600 vs 0644).
