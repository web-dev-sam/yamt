## Behaviour

1. **`--help`** prints the new usage: `usage: yamt [--repo <path>]` / `       yamt --raw`, one sentence that `--raw`
   compares any two pasted texts in two columns, no repository needed, its tabs kept between runs, and a `--raw` line
   in the option list.
2. **`Compare`** never opens a `MergeSession`, never runs git, never calls `appimage::repo_from_start_dir`, never
   manages `Mutex<Merge>` or `HostState`. It builds the app, opens `TabStore` in `<data_dir>/yamt/compare/` and on
   failure ends before any window with exit 2 and one line: `another yamt --raw window is open (<folder>)` (Locked);
   `the stored compare tabs <path> cannot be read: <message>; nothing was changed` (Broken, ReadFailed);
   `the stored compare tabs <path> were written by a newer yamt (format <n>)` (NewerFormat); `no data folder: <error>`.
   Otherwise it manages `Mutex<TabStore>`, reads the settings and applies the font rendering as the merge window does,
   opens the window titled `Compare — yamt` with the same size, background and start script (`window = "compare"`),
   runs `CloseWatch` unchanged, and after `run_return` ends with exit 0 and no message. Split `open_and_wait` so both
   windows share one builder path (no copied window setup).
3. **`load_tab`/`set_column`** lock the store only to call it and clone the `LoadedTab`'s handles, then build the reply
   (`tab_texts`/`comparison`) after the lock is released, on a `spawn_blocking` worker as `merge.rs` does.
4. **Words** for the two new kinds in `problemText.ts` in the file's style (e.g. "That tab was closed" /
   "A column holds up to 8 MiB"; the limit from the reply, written as MiB).
