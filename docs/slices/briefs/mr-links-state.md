## Contract

Fixed here (add-only beyond this):

```ts
// ipc/mergeRequestDomain.ts (+ re-exported from ipc/index.ts): every `page` carries the WebPage brand.
export type LinkedParent = { readonly reference: string; readonly title: string; readonly page: WebPage };
export type LinkedEpic = {
  readonly reference: string;
  readonly page: WebPage;
  readonly shown: { readonly title: string; readonly closed: boolean } | null;
};
export type LinkedIssue = {
  readonly reference: string;
  readonly page: WebPage;
  readonly shown: {
    readonly title: string;
    readonly closed: boolean;
    readonly parent: LinkedParent | null;
  } | null;
};
export type LinkedCommit = { readonly reference: string; readonly page: WebPage; readonly title: string | null };
export type DescriptionLinks = {
  readonly epics: readonly LinkedEpic[];
  readonly issues: readonly LinkedIssue[];
  readonly commits: readonly LinkedCommit[];
};
export type LinksReply =
  | { readonly kind: "read"; readonly links: DescriptionLinks }
  | Readonly<Exclude<Generated.LinksReply, { kind: "read" }>>;
/** Brands every line's and parent's page with `toWebPage` (throws on one that is not https, as `toRowDiscussions`). */
export function toLinksReply(raw: Generated.LinksReply): LinksReply;

// ipc/MergeRequestSource.ts
/** The epics, issues and commits a merge request's description links to, with titles, states and parents; asked
 *  on a row's first hover (plan §2 rows 175–176). */
readLinks(iid: MergeRequestIid): Promise<SourceResult<LinksReply>>;

// ui/mergeRequestLinks.ts — the discussions queue's shape (mergeRequestDiscussions.ts:40-115, 175-214)
export type LinksLoad =
  | { readonly kind: "loading" }
  | { readonly kind: "read"; readonly links: DescriptionLinks }
  | { readonly kind: "refused"; readonly reply: Exclude<LinksReply, { readonly kind: "read" }> }
  | { readonly kind: "failed"; readonly cause: ProblemCause };
export type Links = {
  /** Each asked row's links while this list stands; no entry: not asked since the list was last replaced. */
  readonly links: Readonly<ShallowRef<ReadonlyMap<MergeRequestIid, LinksLoad>>>;
  /** A row's links box opened, or its Retry: asks GitLab unless the row's entry is loading or read. */
  askLinks(iid: MergeRequestIid): void;
};
export type LinkQueue = Links & {
  /** The list was replaced: every entry, every queued ask and any answer in flight are dropped. */
  dropped(): void;
};
export function createLinks(deps: { readonly source: MergeRequestSource }): LinkQueue;
export function linksOf(queue: LinkQueue): Links;
/** A row's links box: its entry, asked when the box opens and when the entry vanishes while the box is open. */
export function useRowLinks(
  links: Links,
  iid: () => MergeRequestIid,
  open: () => boolean,
): ComputedRef<LinksLoad | undefined>;
```

- **The queue** (RK70):
  - `askLinks(iid)` with an entry `loading` or `read` does nothing; with none, `refused` or `failed` it sets
    `loading` and puts `iid` first among the queued asks.
  - One `readLinks` runs at a time; when it settles the next queued iid (the newest ask first) is sent.
  - `dropped()` bumps a generation, empties the map and the queue; an answer of an older generation is dropped.
  - A settled answer: `read` → `read`; any other reply → `refused`; a thrown call or a source failure (`attempt`,
    `problem.ts`) → `failed { cause }`.
- **Log line:** `mergeRequests.links_read { iid, kind, epics, issues, commits, hidden, ms }`: `kind` the reply's kind
  or `"thrown"`, counts zero unless read, `hidden` the lines not shown. Never a title, a reference or an address.
- **The slice** (`ui/mergeRequests.ts`): `State` and `ListState` (`mergeRequestsList.ts:27-39`) gain `linkQueue:
  LinkQueue` (`Pick<LinkQueue, "dropped">` in `ListState`), made by `createState` beside `discussionQueue`
  (`mergeRequests.ts:189`); `MergeRequests` gains `Links` (`...linksOf(state.linkQueue)`, beside `:250`).
- **The refresh rule** (`mergeRequestsList.ts`): `state.linkQueue.dropped()` right after each
  `state.discussionQueue.replaced(…)` (`:63` a refresh's end that swaps the rows in, `:106` a failed first load). Nothing
  else writes the entries.
- **`MergeRequestStep`** (`problem.ts:39-55`) gains `"links"`; `problemText` gives "Could not read the links"
  (`problemText.ts:73`).
- **The app** (`tauriMergeRequests.ts`): `readLinks(iid)` → `converted(toResult(await commands.readLinks(iid)),
  toLinksReply)`, as `readDiscussions` (`:121-125`).
- **The fixture** (`fixtureMergeRequestLinks.ts`, spread into `createFixtureMergeRequests` as `...linksScript(log)`,
  `fixtureMergeRequests.ts:283-287`):
  - `readLinks(iid)` logs `mergeRequests.fixture_links { iid }` first, then answers after `LINKS_PAUSE_MS` 400 ms,
    through `toLinksReply`.
  - **!640, rich** (`ORIGIN` = `fixtureMergeRequestData.ts:11`; group pages on `https://gitlab.example/groups/taskboard`):
    - epics: `&3` "Board redesign"; `&4` "Old board" closed; `design&2` not shown;
    - issues: `#12` "Snooze a reminder" with parent `&3` "Board redesign" (page `…/groups/taskboard/-/work_items/3`);
      `#13` "Write the snooze test" with parent `#12` "Snooze a reminder" (page `${ORIGIN}/-/work_items/12`);
      `other/lib#5` "Fix date parsing" closed, no parent; `secret/vault#9` not shown;
    - commits: `fa3335f3` "Backfill due dates"; `a1b2c3d4…e5f6a7b8` "Commits a1b2c3d4 through e5f6a7b8";
      `secret/vault@0badc0de` not shown;
    - each line's page distinct (`${ORIGIN}/-/work_items/12`, `…/13`, `https://gitlab.example/other/lib/-/issues/5`,
      `${ORIGIN}/-/commit/fa3335f3…`, …).
  - **!639, !637 and every row not named here:** `read` with three empty groups.
  - **!636:** the first ask `failed { message: "glab: a deadline line" }`, each later ask the rich one (a per-iid count
    in the fixture, as `fixtureMergeRequestDescriptions.ts:220-225`).
  - **!634:** `notLoggedIn { detail: LOGGED_OUT_DETAIL }` every time.
