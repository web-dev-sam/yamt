## Change

1. `Theme`: ten variants, kebab-case serde, `name()` for all ten.
2. `window.rs`: ten constants, `background()` with ten arms (exhaustive `match`, no wildcard).
3. Tests (`yamt-settings`): `a_theme_name_is_its_serde_spelling` over all ten (a `data-theme` that differs from the
   file); a file with `"theme": "dark"` / `"light"` reads as `Dark` / `Light` (an old name renamed by mistake); a file
   with an unknown name (e.g. `"vscode"`) is `Error::Broken` and names the field (a typo accepted silently).
   `window.rs`: extend the start-script test with one editor theme (`zed-light`).
4. `crates/settings/AGENTS.md`: name the ten themes if it lists them (one line).
