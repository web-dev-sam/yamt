## Change

1. `style.css`: new tokens and style variables in `@theme static` (yamt Dark values), `--spacing-handle`, the nine
   `@import`s, the utilities; the light block moves out.
2. `themes/*.css`: the nine blocks. Each value from the notes with its source comment; where the notes list a gap or a
   doubt, the design's choice (Q4 shared-kind table, Q6) or amendment 2; a value still unsettled → the code colour
   (`--color-code`'s value) and a comment naming the gap. Syntax colours per the C2 tag mapping applied to each
   editor's table B (TypeScript meaning first, as the design's "one rule for clashing tags" says).
3. Class changes: `island` for `rounded-island` where panels are drawn, `bg-sidebar`/sidebar scroller for the file
   list and the compare tab list, `text-on-*` on the banners and App's success line, the width handle per amendment 1.
4. The check (design Q1 "The check", amended for the shape variables): `scripts/themes.ts` + test with each failure
   path (missing block, extra block, missing or extra token, a bad style or shape value, a background missing or
   different, an editor-theme line without a source comment) and the real tree passing; `palette.ts` keeps literal and
   unknown-token rules with literals allowed in every theme block; its light and window rules move to `themes.ts`.
