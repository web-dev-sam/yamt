## Change

1. **One tint rule.** `paneTone` in `tone.ts`; `sideDecorations` and `centerDecorations` use it (bands unchanged).
2. **Pure marks** (`editor/internal/marks.ts`): places per pane from `Frame`'s rows (side: open there, its tone; Result:
   a side still open, its band's tone) and per problem (`forEachDiagnostic`, `lineBlockAt` for its block, so a problem
   in hidden lines sits on its wave line; hint as info); the lane box from scroller metrics (width
   `max(offsetWidth − clientWidth, 14)`, height `scrollDOM.clientHeight`, track minus both arrow buttons only on
   Windows, arrow height = the scrollbar's width); ticks: top = track top + (padding top + place top) / scroll height ×
   track length, height = the place's share, never under 2 px, inside the track; sorted info < warning < changes <
   error, then top; `tickAt(ticks, y)`: nearest top within 4 px, else none. A target names the change id or the
   diagnostic; positions are read at click time (CM9).
3. **Lanes** (`editor/internal/markLanes.ts`, `MarkLanes`): one `<div class="change-marks" aria-hidden="true" hidden>`
   per shown pane, appended to `view.dom`, `position: absolute; right: 0; top: 0`; `pointer-events: none` on the lane,
   `auto` on ticks (presses between ticks reach the scrollbar); painted above the scrollbar; `hidden` while not shown
   (no hit testing, no work). Dirty on `geometryChanged`, the rows changing (statuses, folds) or `setDiagnosticsEffect`;
   `Frame.request` paints only when shown and dirty — never on scroll. `showMarks(true)` paints at once; `false` hides.
   Theme switches need no repaint (CSS variables).
4. **Click.** `mousedown` (button 0) on a tick: `preventDefault` + stop it (no focus move, no selection, no drag);
   `click`: `tickAt`. Side tick: a new `SideFocus.focusChange(side, id)` over the existing `#focusOn` (outline +
   keyboard, #54). Result tick: cursor to the line's end then to the place's start (a change's first line, a problem's
   start) so `foldField` shows hidden lines, then `center.focus()`. Then that pane's `scrollTop` puts the line a third
   down (new `viewport.ts` `thirdScrollTop`, clamped to 0 and the end); the others follow `scrollSync`.
5. **Wiring.** `MergeOptions.marks`, `showMarks`, `useMergeController` option + watch, `MergeView` prop, the existing
   browser tests and harness pass `marks: false`. Keep `editor/index.ts` ≤ 300 lines.
