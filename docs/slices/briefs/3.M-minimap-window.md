Facts (given; re-check only [INFERENCE]):

- `Frame` (`editor/internal/frame.ts`) is the one per-frame paint and geometry cache (#51): `changed(update)` decides
  whether to `request()` a frame; the frame runs `syncFindSpace`, `layout()`, `ScrollSync.sync(anchors)`, the covered
  drag and `strips.paint`; `ScrollSync` requests a frame on every scroll; `realign()` = `follow("center")`.
- Hosts: `ui/MergeView.vue` grid (`:180`), panes `left`/`center`/`right` (`:222-241`); the right pane's `.cm-editor` fills
  the panes' row and is `position: relative`; an element appended to `view.dom` is outside `scrollDOM`/`contentDOM`, so
  CodeMirror, `SideFocus` (capture on `scrollDOM`), `modClick` and `Folding` (needs `data-fold-run`) never see its
  presses. `@codemirror/view` stacking: `.cm-panels` z 300, gutters 200 inside the scroller's own context, tooltips 500.
- The Result is shown as text unless `MergeView`'s `centerLine` is non-null (its "not text" / "deleted" line, `:97-103`);
  no minimap then (plan #81). Choice views have no panes (#36/#47).
- The hold: `ui/altHold.ts` `useAltHold()` (untouched since #80; App no longer calls it after the cutover).
- Theme: App writes `data-theme` on the root; `MergeController.setPreferences` dispatches the panes' dark flag
  (`EditorView.darkTheme` facet); colours are CSS variables in `style.css` (palette test VU17: colours only from
  `@theme`, both themes define the same tokens).
- Problems: `@codemirror/lint` state in the Result only, `problems.ts` `linted(transactions)` flags new diagnostics.
- `pnpm -C frontend test:browser` cannot launch Playwright WebKit on this host and is not in CI (#1074, #1222): write no
  new `*.browser.test.ts`; your WebKit proof is MiniBrowser through `just webdriver 4447`.
- `editor/` is not mutation-tested (VF7); `ui/useMergeController.ts` is.
- Size caps: 300 lines per file, 40 per function (`.oxlintrc.json`).

## Change

1. **Element** (design Option A §1): one `<div class="minimap" aria-hidden="true">` holding a `<canvas>` and a
   `<div class="minimap-slider">`, appended to `views.right.dom`; `theme.css`: absolute at the right edge, top 0 to
   bottom 0, width `minimapColumns(dpr).width / dpr` CSS px, `max-width: 100%`, `background: var(--color-panel)`,
   `border-left: 1px solid var(--color-control-border)`, `visibility: visible`, `z-index: 400`, `display: none` while
   hidden; canvas `opacity: 0.9` (VS Code `minimap.css`).
2. **Owner:** `Frame` owns `Minimap`: `changed` asks it (only while shown), the frame paints it after `scroll.sync`
   (the Result's `scrollTop` is then current), `showMinimap` shows/hides and requests a frame, `destroy` destroys it.
3. **Tiles** (`minimapTiles.ts` `MinimapTiles`): `TILE_ROWS` rows rendered once into a detached canvas through
   `ImageData` (`paintRow`, `paintWave`, `putImageData`); each row's text `sliceDoc(block.from, block.from + 120)`,
   its colours from `highlightTree(syntaxTree(state), syntaxColourClasses, …)` mapped to the palette, unparsed text in
   `--color-code`; a collapsed run's row (from `layout.waves`' center rows) drawn with `paintWave`; tabs at
   `state.tabSize`. Dropped per `staleTiles` (document, folds, theme, language → all; tree growth → from the old
   length); tiles outside the window ±1 dropped; all dropped while hidden.
4. **Per frame while shown:** read the Result's `scrollTop`, `clientHeight`, `documentPadding`, the row count from
   `lineBlockAt(doc.length).bottom`, the box `clientHeight` and `devicePixelRatio`; `minimapLayout(input, previous)`;
   write the slider's `transform`/`height` only when changed (none when `slider` is null); only when the window, padding
   rows, tiles or size changed: `clearRect`, then `drawImage` the window's tiles, then the edges. Nothing else measured.
5. **Edges:** `changeMarks(layout.rows)` on the right edge, `problemMarks(state, blockAt)` on the left edge, each through
   `markBoxes(…, columns.right / columns.left)`, painted after the tiles in their tokens (`--color-mark-inserted/
   -modified/-deleted/-conflict`, `--color-problem-error/-warning`); cached until `rowsMoved` or `linted(…)`.
6. **Colours:** `getComputedStyle(minimap).getPropertyValue(token)` for `--color-code`, every `SYNTAX_COLOURS` token,
   `--color-diff-wave` and the six edge tokens through `rgbOf`, read when shown and on the next frame after the
   Result's `darkTheme` facet changes (light = not dark); never per frame.
7. **Pointer** (design §6): `mousedown` on the box `preventDefault` + `stopPropagation` (focus, selection stay);
   `pointerdown` (button 0 or non-mouse) on a row → the Result's `scrollTop = centredScrollTop(rowAt(…), input)`, then
   `ScrollSync.follow("center")`; on the slider → `stopPropagation`, `setPointerCapture`, class `active`, drag with
   `draggedScrollTop(start, clientY − startY)` + `follow`; `pointerup`/`pointercancel`/`lostpointercapture` end it;
   `show(false)` mid-drag releases the capture and ends it. Wheel (passive) → the Result's `scrollBy` in pixels
   (lines × 20, pages × `clientHeight`) + `follow`.
8. **Hidden costs nothing:** `changed`/`paint` return on their first line while hidden; no listener does work.
9. **Wiring** per the contract; the two browser tests pass `minimap: false`; `editor/AGENTS.md` gets one paragraph on
   the minimap (owner, element, when it paints, the pointer). Keep `editor/index.ts` ≤ 300 lines. `useMergeController`
   is at ~39 of 40 lines per function since the cutover inlined its watches (#1225): put the `preferences`,
   `collapsed` and `minimap` watches back in one helper (`followWithoutRebuild`, as before #80's removal).

## Acceptance

   loads); every pure helper you add gets a node test with a hand mutation shown failing and restored.
2. `pnpm -C frontend lint`, `typecheck`, `test`, `unused`, `fmt:check`, `just sfc-order`: exit 0, tails pasted;
   `wc -l frontend/src/editor/index.ts`.
3. Failing paths (editor/ is not mutated), each shown failing in the WebKit step it breaks, then restored: `show(false)`
   not hiding; the press not stopped (the right pane gets a selection or the keyboard); edges not dropped on `rowsMoved`
   (an applied change keeps its mark).
4. WebKit fixture page (`pnpm -C frontend dev --port 5277`, `just webdriver 4447`, window 1600×1000, a golden long
   enough to scroll with far-apart changes and a conflict), Alt held by WebDriver key actions (keyDown without keyUp):
   a. before Alt: `.minimap` not displayed; `elementFromPoint` at the right pane's right edge is its `.cm-scroller`;
   b. Alt held: displayed; its rect's right, top and bottom equal the right pane's `.cm-editor`; nothing else moved
   (the three panes' rects before and after equal); Alt up hides; Alt then `a` hides; a `blur` hides and a repeated
   Alt keydown does not show it, a fresh one does;
   c. canvas pixels: a keyword's row in the keyword token's colour (within the glyph blend), a collapsed run's row in
   `--color-diff-wave`; collapsing toggled with Alt held → rows redrawn (row count differs);
   d. right edge: one mark per waiting change in its token, the conflict in `--color-mark-conflict`; apply a change by
   its strip icon while Alt is held → its mark gone in the next frame;
   e. scrolling the Result moves the slider to `minimapLayout`'s top and height; in a long file the minimap's window
   moves; at the end the last row is the last drawn;
   f. a press on a row → the Result's `scrollTop` equals `centredScrollTop`, the sides' `scrollTop` changed;
   `document.activeElement`, the Result's selection, the folds and the right pane's selection unchanged; a slider
   drag of 50 px gives `draggedScrollTop`; a wheel over it scrolls the Result;
   g. Light theme (Settings): the keyword pixel and the background follow the light tokens;
   h. no `.change-marks` anywhere; no console errors. Screenshots `/tmp/yamt-m/window-*.png` (dark, light, a long file).
5. Real app with language servers: `scripts/lsp-repo.sh --servers /tmp/yamt-m/lsp`, `just app-session start-app --name
   m-window --repo /tmp/yamt-m/lsp` (or `pnpm -C frontend exec tsx scripts/app-session.ts …` when arguments carry
   quotes, #1221), open a conflicted file with problems, start its servers; `DISPLAY=:<d> xdotool keydown alt` → left
   edge red for an error and yellow for a warning, none for info; `xdotool` click on a row centres it, the cursor and
   focused pane unchanged; drag the slider; `focus-away` hides; `keyup alt`. Stop every session; nothing left running.
