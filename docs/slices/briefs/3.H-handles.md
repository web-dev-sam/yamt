## Behaviour

1. **MergeView**: the section's `grid-template-columns` is `paneColumns(paneSplit, "strip")` (the `grid-cols-[…]`
   class goes). Each header-row cell above a strip becomes the divider's handle: `role="separator"`,
   `aria-orientation="vertical"`, `aria-label` "Local and Result widths" / "Result and Remote widths", `cursor-col-resize`,
   the dots centred. Each strip wrapper gets `cursor-col-resize` and the same listeners (`usePaneDividers`, measuring
   the three pane hosts at the press). Icons and wave joins keep their own cursor and presses.
2. **ChoiceView**: the same split through `paneColumns(paneSplit, "gap")` (1 px gutters showing the separator colour,
   column starts 1/3/5); each gutter gets a hit box 2 px wider on each side (`z-10`), `role="separator"`, the dots
   centred vertically.
3. **FileList**: `useColumnDrag` replaces `startResize`/`resize`; the width comes from `createFileListWidth` (created in
   the component like `createFileListMode`), each move `setWidth(px, window.innerWidth)`; a double-click resets to the
   starting width; the dots centred in the 5 px gap.
4. **ResizeDots**: `bg-handle` at rest; `bg-handle-active` on `hover` after 300 ms (transition delay in, none out, VS
   Code's `Sash` hover delay) and at once on `drag`.
5. **style.css**: `--color-handle` and `--color-handle-active` in both theme blocks (the design's values: dark
   `#565362` / `#aba9b6`, light `#aeb3c2` / `#767a8a`; the palette test must pass); `:root.<COLUMN_RESIZING_CLASS> *
   { cursor: col-resize !important; user-select: none !important; }`.
6. **editor/theme.css**: `path.chunk-band { pointer-events: none; }` (so a press on a band reaches the svg root and
   drags the divider).
7. **Unchanged** (rule 7): the locked scroll, bands, waves (#64 via `WavePhases`' resize observer), the minimap's place,
   the find bar, the keyboard and the selection during a drag.
8. **app-session** commands as in the contract, with their argument tests in `args.test.ts`.
