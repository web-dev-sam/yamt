## Contract (fixed; you may add, never change)

- `yamt-cli range <repo-dir> <range>` prints one JSON document `{ "start": RangeStart, "files": RangeFile[] }` to
  stdout, where `files[i]` is `Range::load(RangeFileId(i))` for every listed file in list order (the index is the id);
  a `yamt-range` error → its message on stderr, exit 2.
- `scripts/range-repo.sh <dir>` builds the smoke repository into `<dir>` (refuses a non-empty `<dir>`), with fixed
  names and dates so its commit ids never change, and prints the command to open it.
- Cases: `frontend/fixtures/range/review.json` = `main...feature` and `empty.json` = `feature..feature`, generated by
  building `scripts/range-repo.sh target/range-repo` (on disk, RK27) and running `yamt-cli range` on it.
