   `GIT_DIR`, `GIT_WORK_TREE`, `GIT_INDEX_FILE`, `GIT_COMMON_DIR`, `GIT_OBJECT_DIRECTORY` and
   `GIT_ALTERNATE_OBJECT_DIRECTORIES` from every git command run on the clone (`clone_shared_into`'s own
   `Repo::discover(&into)` included) and from the agent's environment. A test through
   `yamt_conflict_repo::run_ignored_in_child` with `GIT_DIR=<source>/.git` asserts the source's branches, remote and
   HEAD are unchanged after `prepare`.
2. **Discard's failures tested** (`agent/src/checkout.rs:58`, `:87`; 4 survivors): `discard_without_a_checkout_succeeds`
   (twice, or before `prepare` → `Ok(())`); unix `discard_that_cannot_rename_the_checkout_answers_remove_and_keeps_it`
   (pair folder 0o555 → `Err(Error::Remove { folder })`, `folder == checkout`, `a.txt` still there, permissions
   restored); unix `discard_that_cannot_delete_the_checkout_answers_remove` (`checkout/sub` holding a file at 0o555 →

3. **The sweep never refuses a window** (`agent/src/sweep.rs:16`): skip pair folders holding none of `checkout`,

   `remove_leftovers` treats a `.removing` that vanishes mid-walk as done. A test: a `PairLock::take` during a sweep of
   a pair with nothing to sweep succeeds.
