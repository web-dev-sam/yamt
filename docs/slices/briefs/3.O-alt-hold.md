## Contract (fixed; you may add, never change)

```ts
// ui/altHold.ts
export type HoldEvent =
  | { readonly kind: "keydown"; readonly key: string; readonly repeat: boolean }
  | { readonly kind: "keyup"; readonly key: string; readonly altKey: boolean }
  | { readonly kind: "pointer"; readonly altKey: boolean }
  | { readonly kind: "left" }; // window blur, or the page hidden
export function heldAfter(held: boolean, event: HoldEvent): boolean;
export function useAltHold(): Readonly<ShallowRef<boolean>>;
```

App.vue: `const altHeld = useAltHold();` once, and `:marks="altHeld"` on every `<MergeView>`.

## Change

1. `heldAfter`, pure, one rule per case (plan #80 "Hold"):
   - `keydown` `"Alt"`: not a repeat → `true`; a repeat → unchanged (Alt's key repeat never brings marks back after
     another key hid them, and coming back to the window with Alt held shows nothing until a fresh press);
   - `keydown` of any other key, `"AltGraph"` included → `false` (Alt+key is a shortcut, not a hold);
   - `keyup` `"Alt"` → `false`; any other `keyup` with `altKey` false → `false` (a release the window missed); else
     unchanged;
   - `pointer`: `held && altKey` (a pointer event never shows them; one reporting Alt up hides them);
   - `left` → `false`.
2. `useAltHold`: one `shallowRef(false)`; window `keydown`/`keyup` in the capture phase (a find box or menu that stops
   propagation must not hide a release); window `blur` and the document becoming hidden (`useDocumentVisibility` or a
   `visibilitychange` listener) → `left`; `pointerdown`, `pointermove`, `pointerup` and `wheel` on the window, capture
   and passive, registered **only while held** (nothing listens while Alt is up: VueUse `useEventListener` with a
   reactive target, or your equivalent), each mapped to `pointer` with the event's `altKey`. No `preventDefault`
   anywhere (Alt reaches the page and every other listener as before, plan #80 "Windows").
3. App.vue wiring per the contract, beside the existing window listeners.
