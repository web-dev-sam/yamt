## Blocks to fix (verbatim from the reviews; 1–4 are blocks, 5 promoted)

1. **No anchor past the file's end** (`threadNumbers.ts:127`): the press handler accepts CodeMirror's trailing empty line
   ("a\nb\n" is 2 git lines, CodeMirror draws 3) and an added or deleted file's empty column (one empty line 1), giving
   anchors neither commit has. Return false for `line >= gitLines(doc)` (`doc.lines` minus 1 when the last line is
   empty: 0 for "", 2 for "a\nb\n"). Tests in `threadNumbers.test.ts`/`threadAnchor.test.ts` for the trailing empty line
   and an added file's empty left column.
2. **One rule for a thread's shown column and line** (`threadNumbers.ts:21`): add `shownLine(line): { column: Column;
   line: number }` to `ipc/threadLine.ts` as the one exhaustive switch; `shownColumn` is `shownLine(line).column`;
   export it from `ipc/index.ts`; delete `lineInShownColumn`; `lineCounts` reads both from one call.
3. **An empty side's band point counts the gap rows** (`threadField.ts:34`): in a pure deletion (insertion) the empty
   side's gap rows sit at the end of line rs−1, joined into its block, while `rangeSpan` measures the empty span at line
   rs's block top — filler outside the band, the band edge off by the box height, scroll sync drifting above. Put an
   empty side's gap rows before line rs (negative side at its `from`, as place 0 does) and leave unchanged rows after
   rs−1; in `columnSpan`, measure an empty range as the joined block's top to its text part's top (the compare window's
   old point when there are no widgets). A `compareFrame.test.ts` case with a removed-line row in a pure deletion: both
   edges in both columns, and the follower's scrollTop.
4. **Forget a field the user left** (`threadHosts.ts:141`): clear `#focused` in a capturing document `pointerdown` when
   the press is outside every host; remove the listener in `destroy()` beside the `focusin` one. A detach caused by
   scrolling still restores focus; a field the user left does not.
5. **`ThreadHosts` after the views** (`range.ts:66`): build it after `createReadOnlyColumnViews`, pass `views` directly,
   observe the scrollers and gutters in its constructor; remove the views thunk and `watchColumns()`.
