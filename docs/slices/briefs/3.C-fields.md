## Contract (fixed; you may add, never change)

```ts
// tone.ts — the one tint rule, also behind chunkTone for non-conflicts
export type ChangeTone = Exclude<Tone, "conflict">;
export function changeTone(baseLines: number, changedLines: number): ChangeTone; // base 0 → inserted, changed 0 → deleted, else modified

// decorations.ts
export type Band = { readonly from: number; readonly to: number; readonly tone: Tone };
export function bandDecorations(doc: Text, bands: readonly Band[]): DecorationSet;

// words.ts — sideWordDecorations loops chunks over it
export function wordDecorations(doc: Text, words: SideWords<number>, tone: Tone): Range<Decoration>[];

// compareMarks.ts — pure: one column's spans and marks for a comparison
export type DiffSpan = { readonly from: DocPos; readonly to: DocPos; readonly tone: ChangeTone };
export type ColumnMarks = { readonly spans: readonly DiffSpan[]; readonly bands: DecorationSet; readonly words: DecorationSet };
export function columnMarks(doc: Text, differences: readonly Difference[], column: Column): ColumnMarks;

// compareFields.ts — per column, built once per reply, mapped through edits
export const showDifferences: StateEffectType<ColumnMarks>;
export const differenceField: StateField<ColumnMarks>; // provides bands + words as decorations
// mapping: from with assoc -1, to with assoc -1 (typing on the line after a difference stays outside it, typing inside grows it)

// compareSettle.ts
export const SETTLE_PAUSE_MS = 300;
export type Timers = { readonly set: (run: () => void, ms: number) => number; readonly clear: (id: number) => void };
export class Settle {
  constructor(versions: ColumnVersions, settled: (columns: readonly Column[]) => void, timers?: Timers);
  edited(column: Column): void;                 // the column's version + 1 (nextColumnVersion), the pause restarts
  versions(): ColumnVersions;
  accepts(versions: ColumnVersions): boolean;   // a reply applies only when both equal the current versions
  settleNow(): readonly Column[];               // the columns edited since their last settle; cancels the timer
  destroy(): void;
}

// columnBytes.ts
export function utf8Length(text: string): number;                     // pure, no TextEncoder allocation of the whole text
export function columnLimit(limit: number, refused: () => void): Extension; // byte count per column updated from each change; a transaction that would pass `limit` is refused and `refused` called

// compareNavigation.ts — next/previous difference from the cursor, no wrap
export function nextDifference(spans: readonly DiffSpan[], cursor: DocPos, direction: Direction): DiffSpan | null;
```

## Behaviour

1. **Colours** (plan §2 #93): a difference's tone is `changeTone(left.len, right.len)` for both columns and its band;
   word marks and removal bars in both columns with that tone. `chunkTone` keeps its answers for merges (it calls
   `changeTone` for non-conflicts: one tint rule).
2. **Marks are built once per reply**: `columnMarks` builds bands (point bands for an empty side, as the merge window
   does) and words; the field replaces them on `showDifferences` and otherwise maps spans and both sets through
   `tr.changes`, never rebuilding per key.
3. **Settle**: every edit of a column calls `edited`; after `SETTLE_PAUSE_MS` without an edit `settled` is called once
   with exactly the columns edited since their last settle; `settleNow` returns them and cancels the pause; a reply
   whose versions are not both current is refused by `accepts`.
4. **Byte limit**: the count is exact in UTF-8 (a three-byte character counts three) and costs the size of each change,
   not of the document; exactly at the limit is allowed.

## Acceptance

Node tests (each naming its bug and its proved hand mutation; design §8 lists them): `compareMarks.test.ts` (left empty
→ inserted, right empty → deleted ← `changeTone` arguments swapped; word marks and bars at the right offsets in both
columns ← `line + 1` dropped); `compareFields.test.ts` (typing inside a difference grows it, typing on the next line
stays outside ← `to` mapped with +1; marks are mapped, not rebuilt ← the field ignores `tr.changes`; the effect replaces
both sets); `compareSettle.test.ts` with fake timers (one `settled` after the pause with only the edited columns ← the
edited set not cleared; a reply with an old right version is refused ← only one column compared; `settleNow` cancels
the timer ← timer left running); `columnBytes.test.ts` (a three-byte character over the limit is refused ← UTF-16
length counted; exactly at the limit accepted ← `>=`); `compareNavigation.test.ts` (next/previous from the cursor, no
wrap ← a modulo wrap); `tone.test.ts`/`words.test.ts`/`decorations.test.ts` (merge answers unchanged). Commands:
`pnpm -C frontend typecheck`, `test`, `lint`, `unused`, `fmt:check`.
