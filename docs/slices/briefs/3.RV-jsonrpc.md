# Slice 3.RV-jsonrpc — one JSON-RPC connection for language servers and the AI agent: `frontend/src/jsonrpc/`

Board "Review a commit range" row 11 (C5a; needs nothing of A or B). Product rule: `docs/plan.md` §2 **#109** (the
window's `agent/` speaks ACP over a shared `jsonrpc/` moved out of `lsp/internal`) and #70 — read them. Design:
`.omp/run/notes/AgentDesign.md` the build table's C5a line, "3. The agent protocol in the window". Row 12's `agent/`
(C5b) is the second user.

Facts (given):

- `frontend/src/lsp/internal/connection.ts` (135 lines): `Reply = result | error { message } | timedOut | closed`,
  `ConnectionHandlers { send, request: (method, params) => Answer, notification, log }`, `class Connection` with
  `request(method, params, timeoutMs)` (on timeout it sends `$/cancelRequest { id }`, logs, settles `timedOut`),
  `notify`, `receive(text)` (valibot parse through `messages.ts`, malformed → logged and dropped), `close()` (every
  pending settles `closed`). `messages.ts` (83 lines): `Incoming`, `parseIncoming`, `requestText`, `notificationText`,
  `resultText`, `errorText`. `timers.ts`: `Timers`, `SYSTEM_TIMERS`. `Answer` lives in `lsp/internal/answers.ts`.
  Their users: `lsp/index.ts`, `lsp/internal/{answers,attempt,attempt.test,documents,formatting,handshake,problems,
  server,serverDocs}.ts`; tests `connection.test.ts`.
- The agent's needs (measured on `omp acp`): a `session/prompt` request has no deadline and is cancelled by the
  notification `session/cancel { sessionId }`, not `$/cancelRequest`; omp's errors put the real text in
  `error.data.details` with `message: "Internal error"` (e.g. `{"code":-32603,"message":"Internal error","data":
  {"details":"ACP session not found: …"}}`), so the error reply must carry `data`.
- `frontend/scripts/fences.ts` PM3 lists the framework-free modules (`lsp` among them); PM5 forbids importing another
  module's `internal/`; `frontend/.oxlintrc.json` and `frontend/vite.config.ts` (orchestrator-editable; report needed
  lines) may list module folders.

## Contract (fixed; you may add, never change)

```ts
// frontend/src/jsonrpc/index.ts — framework-free (PM3), imports nothing from other src/ modules
export type Answer = /* moved from lsp/internal/answers.ts unchanged */;
export type Reply =
  | { readonly kind: "result"; readonly value: unknown }
  | { readonly kind: "error"; readonly code: number; readonly message: string; readonly data: unknown }
  | { readonly kind: "timedOut" }
  | { readonly kind: "closed" };
export type ConnectionHandlers = { send; request: (method, params) => Answer; notification; log };  // unchanged
export type ConnectionOptions = { readonly cancelNotification: string | null };   // LSP: "$/cancelRequest"; ACP: null
export class Connection {
  constructor(handlers: ConnectionHandlers, timers: Timers, options: ConnectionOptions);
  request(method: string, params: unknown, timeoutMs: number): Promise<Reply>;   // on timeout: the cancel notification if any, logged, timedOut
  requestUntilAnswered(method: string, params: unknown): Promise<Reply>;          // no deadline; settles on its answer or close()
  notify(method: string, params: unknown): void;
  receive(text: string): void;
  close(): void;
}
export { type Timers, SYSTEM_TIMERS } from "./timers";
export { type Incoming, parseIncoming, requestText, notificationText, resultText, errorText } from "./messages";
```

## Change

1. Move `connection.ts`, `connection.test.ts`, `messages.ts`, `timers.ts` (and the `Answer` type) into
   `frontend/src/jsonrpc/`; add `ConnectionOptions`, `requestUntilAnswered`, `code` and `data` on the error reply.
2. `lsp/` imports from `../jsonrpc` and passes `{ cancelNotification: "$/cancelRequest" }`; its error handling reads
   `message` as before.
3. `fences.ts`: `jsonrpc` is framework-free (PM3), imports no other `src/` module, and `lsp/` may import it; tests.
