## Change

1. **Toolbar:** Abort merge becomes the first icon button, right after "Mark resolved" (id yours, label "Abort merge",
   icon `~icons/lucide/git-pull-request-closed`, `run` = the store's `abortMerge`). It shows only while git has a merge to
   abort **and** the user has not hidden it; disabled while the abort runs and after a success (not tied to `summary`); a
   press leaves the keyboard where it was after Cancel, as the other keyboard-keeping buttons.
2. **Menu:** `ToolbarMenu` lists Abort merge first, with its check mark, only while git has a merge to abort (otherwise
   the seven as today).
3. **Hidden at first, for everyone:** Abort merge starts hidden, also for a user who toggled any toolbar button before.
   Change the stored value so it names each decided button, shown or hidden (#58): a button nobody decided takes its own
   starting state (Undo, Redo, Abort merge hidden; the rest shown). An array stored before this change (the hidden ids)
   still reads: in it → hidden, absent → shown, for the seven ids it can name; Abort merge takes its start state. Keep:
   unknown ids dropped, unreadable storage = the starting state, defaults never written, one key or a new one (your
   call; say which and why — a new key must still read the old one).
4. **File list:** remove the header button, its prop and emit, the `App.vue` wiring, and the `mr-auto` it needed
   (the header returns to its pre-feature markup).
5. Two meanings of "hidden" (git has no merge vs the user hid it) must not share one word: rename `AbortButton`'s
   no-merge state (or the type) so a reader can tell them apart.

## Tests (node, `ui/`)

Behaviour: Abort merge hidden at the first start; a user's old array (e.g. `["undo"]`, `[]`, `["undo","redo"]`) keeps
those seven decisions and leaves Abort merge hidden; showing it stores the decision and survives a second start; a later
unknown id in the new format is dropped; the toolbar shows the button only when git has a merge to abort and it is not
hidden; the menu lists it only while git has a merge to abort. Rewrite the format-pinning tests of the old array to the
new rules; delete any that pinned only the old format. `just mutants` runs on your lines.
