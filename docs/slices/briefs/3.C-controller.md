## Contract (fixed; you may add, never change)

```ts
// editor/compare.ts — re-exported by editor/index.ts
export type CompareHosts = { readonly left: HTMLElement; readonly right: HTMLElement; readonly strip: SVGSVGElement };
export type CompareOptions = { readonly preferences: Preferences; readonly language: TabLanguage; readonly columnLimit: number };
export type ColumnText = { readonly column: Column; readonly text: string; readonly version: ColumnVersion };
export type ColumnFormat =
  | { readonly kind: "formatted" | "unchanged" }
  | { readonly kind: "failed"; readonly message: string; readonly line: number };
export type FormatReport = Readonly<Record<Column, ColumnFormat>>;
export type CompareEvents = {
  readonly settled: (columns: readonly ColumnText[]) => void; // after SETTLE_PAUSE_MS, only the columns edited since their last send
  readonly detected: (language: string | null) => void;       // Auto's finding, at build and whenever it changes
  readonly refused: (column: Column) => void;                 // an edit that would pass columnLimit bytes
};
export class CompareController {
  constructor(texts: TabTexts, hosts: CompareHosts, options: CompareOptions, events: CompareEvents);
  showComparison(comparison: Comparison): boolean; // false = versions not current, dropped
  setLanguage(language: TabLanguage): void;         // both columns at once
  setPreferences(preferences: Preferences): void;
  formatLanguage(): "JSON" | "XML" | null;          // the picked language, else Auto's finding; null = Format disabled
  format(): FormatReport;                           // one "yamt.format" transaction per changed column
  moveToChange(direction: Direction): void;         // next/previous difference from the cursor of the focused column (left when none), no wrap
  holdsText(): boolean;
  settleNow(): readonly ColumnText[];               // the unsent columns, timer cancelled (close, tab close)
  destroy(): void;
}
export function languageNames(): readonly string[]; // every @codemirror/language-data name, sorted
export const FORMAT_LANGUAGES: readonly ["JSON", "XML"];
```

## Behaviour

1. **Views**: two `"center"` panes with the user's keys and theme, `differenceField`, `columnLimit`, the removal
   tooltip and find; texts from `TabTexts`, the first `showComparison(texts.comparison)` applied at build. Undo/redo by
   keyboard per column; `historyKey` so Ctrl/Cmd+Z reaches the focused column.
2. **Strip**: one strip of keyed band paths between the columns (`chunk-<tone> chunk-band`, the tone of
   `changeTone(left.len, right.len)`), painted once per frame from a cached row list (`CompareFrame`: rows recomputed
   only when spans, measured heights or the documents change, never per scroll; plan §2 #51); a press on the strip
   does nothing (`preventDefault`, as `strips.ts`).
3. **Locked scroll** through the generalised `ScrollSync` with the two columns' anchors from the difference rows (the
   merge window's rule: proportional between anchors).
4. **Differences**: every edit goes to `Settle.edited`; `settled` hands out the unsent columns' texts with their
   versions; `showComparison` applies a reply only when `Settle.accepts` its versions, then dispatches `showDifferences`
   to both columns; until then the marks follow the edits by mapping.
5. **Format**: `formatLanguage()` picks `formatJson`/`formatXml`; each column is formatted alone; a `formatted` result
   is one whole-document replace (`userEvent: "yamt.format"`, cursor to the start, one undo step), `unchanged` and
   `failed` dispatch nothing; the report names each column's outcome.
6. **Language**: `TabLanguage.auto` → `detectLanguage` at build and after each settle; the finding reaches the panes
   (`languageCompartment`, lazily loaded as today) and `detected` fires only when it changed; `picked` → that language,
   `detected` not fired. Plain text = no language.
7. **Merge window unchanged**: the generalised `ScrollSync`, `syncFindSpace` and `loadLanguage` keep the merge window's
   behaviour (its tests unchanged in what they assert); `editor/index.ts` stays ≤ 300 lines.
