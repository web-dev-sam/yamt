# Slice 3.X-aa-desktop — the Antialiasing setting: file, command, applied to GTK at start (Linux)

disagree, #60 wins — report it). Measurements behind it: `.omp/run/notes/CrispTextProbe.md` (given facts; do not

## Target

Owned: `crates/settings/**`, `src-tauri/src/**`.
Read-only: everything else. Already done by the orchestrator: `gtk = "0.18.2"` in `[workspace.dependencies]` and
`gtk.workspace = true` under `[target.'cfg(target_os = "linux")'.dependencies]` of `src-tauri/Cargo.toml` (the GTK 3
binding tauri already runs on; no new package in `Cargo.lock`). Generated, never edit: `frontend/src/ipc/bindings.ts`
(the orchestrator runs `just bindings` after your patch; the window side is the next slice).

Non-goals: any frontend change; applying a change to the running window (the setting applies at the next start, #60);
macOS/Windows behaviour (the setting is stored there but does nothing); hinting, font or size changes; environment
variables or engine switches (`WEBKIT_*`: measured useless, #60).

## Contract

Fixed (exists): `Theme`, `KeysChange`, `SettingsRead`, `Error`, `read`, `set_theme`, `set_keys`, `relocate`, `Places`;
the four existing commands' names and arguments; `IpcError`.

New / changed (names fixed):

```rust
// crates/settings/src/lib.rs
#[derive(Clone, Copy, Debug, Default, PartialEq, Eq, Serialize, Deserialize, specta::Type)]
#[serde(rename_all = "lowercase")]
pub enum Antialiasing { #[default] Subpixel, Greyscale }   // file values "subpixel" | "greyscale"

pub struct StoredSettings { pub theme: Theme, pub antialiasing: Antialiasing, pub keys: BTreeMap<String, Vec<String>> }

pub fn set_antialiasing(places: &Places, current: &StoredSettings, antialiasing: Antialiasing)
    -> Result<SettingsRead, Error>;

/// Replaces `theme_at_start`: the file in use's settings, defaults when anything on the way is missing,
/// unreadable or broken; never writes.
pub fn stored_at_start(places: &Places) -> StoredSettings;
```

- File: entry `"antialiasing"`; missing → `Subpixel`; any other value → `Error::Broken` naming the entry (as `theme`).
- `src-tauri`: command `set_antialiasing(window, current: StoredSettings, antialiasing: Antialiasing) ->
  Result<SettingsRead, IpcError>`, same shape as `set_theme` (writes, returns the read, nothing applied live),
  registered beside the others.
- Linux only (`#[cfg(target_os = "linux")]`), a new module `src-tauri/src/font_rendering.rs`:
  - a pure function choosing GTK's `gtk-xft-rgba` value from the setting and the desktop's current value — Subpixel:
    the desktop's value when it is `rgb`, `bgr`, `vrgb` or `vbgr`, otherwise `rgb`; Greyscale: `none` — unit-tested
    over every input class;
  - `apply(antialiasing)`: on `gtk::Settings::default()` set `gtk-xft-antialias` = 1 and `gtk-xft-rgba` = that value;
    `tracing::info!` the setting and the rgba it set; no settings object → a warning, nothing else.
- `window.rs`: read `stored_at_start` once (theme and antialiasing from the same read; `start_theme` follows), and on
  Linux call `font_rendering::apply` after the app is built (GTK is initialised) and **before** the
  `WebviewWindowBuilder` builds the webview (WebKitGTK fixes its surfaces' subpixel layout at start, #60).

## Change

1. Settings crate: the enum, the field, the file entry, `set_antialiasing`, `stored_at_start` (remove `theme_at_start`
   and move its tests); tests for: a missing entry reads `Subpixel`; `"greyscale"` reads back; an invalid value is
   `Broken` and the file is not rewritten; `set_antialiasing` keeps unknown entries and the other settings;
   `stored_at_start` gives defaults for a missing, unreadable and broken file and the file's values otherwise.
2. `src-tauri`: the command, `font_rendering.rs` with its unit tests, the start-up order in `window.rs`.
3. `crates/settings/AGENTS.md` / `src-tauri/AGENTS.md` if they list the crate's functions or modules.
