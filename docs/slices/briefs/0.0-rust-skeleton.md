# Slice 0.0 — Rust walking skeleton

## Target
Owned: `Cargo.toml`, `Cargo.lock`, `rust-toolchain.toml`, `deny.toml`, `clippy.toml`, `justfile`,
`crates/**`, `src-tauri/**`, `.cargo/**`, `scripts/arch-check.sh`
Read-only: `docs/**`, `.omp/**`, `AGENTS.md`
Non-goals: any diff logic, any git logic, any Tauri window, any frontend file. Every crate is
empty except its `lib.rs` crate-doc line and, where listed, one placeholder type.

## Contract
- Workspace members: `crates/merge-core` (package `yamt-merge-core`), `crates/gitio`
  (`yamt-gitio`), `crates/session` (`yamt-session`), `crates/cli` (`yamt-cli`, binary `yamt-cli`),
  `src-tauri` (`yamt-app`, binaries `yamt` and `export-bindings`).
- Dependency edges exactly as `docs/architecture.md` §2: session → merge-core, gitio;
  cli → session; src-tauri → session. gitio must not depend on merge-core.
- Workspace `[lints]` per `docs/architecture.md` §7 and `skill://rust-conventions` (clippy
  pedantic warn; unwrap_used/expect_used/panic/unreachable deny; wildcard_enum_match_arm deny;
  too_many_lines threshold 40 via `clippy.toml`; unsafe_code forbid; missing_docs warn on
  merge-core only).
- `clippy.toml` `disallowed-methods`/`disallowed-types` for merge-core: `std::process::Command`,
  `std::fs::*` read/write functions.
- `deny.toml`: licenses allow MIT/Apache-2.0/BSD-2/BSD-3/ISC/Unicode/Zlib/MPL-2.0; advisories deny
  unmaintained warn; bans: multiple-versions warn.
- `rust-toolchain.toml`: current stable channel (pin the exact version installed on this machine).
- `src-tauri`: NO tauri dependency yet. `yamt-app` has `specta` + `specta-typescript` only, with one
  placeholder DTO `Ping { ok: bool }` and `src/bin/export-bindings.rs` that writes
  `frontend/src/ipc/bindings.ts` containing the exported `Ping` type. (Tauri itself lands in M2;
  the bindings pipeline is proven now.) If `specta-typescript` cannot export without tauri-specta,
  report in `deviations_from_brief` and still produce the file by hand-formatting from specta's
  `DataType` — generated output is what matters.
- `justfile` recipes exactly: `check`, `fmt-check`, `clippy`, `test`, `deny`, `bindings`,
  `bindings-check`, `web-lint`, `web-typecheck`, `web-test`, `arch-check`, `sfc-order`,
  `dev-web`, `dev-app`, `smoke-cli`, `golden-update` as listed in `docs/architecture.md` §7.
  `web-*`, `sfc-order`, `dev-web` call into `frontend/` via `pnpm -C frontend …` and must
  tolerate `frontend/` not existing yet by skipping with a printed notice (`test -d frontend || …`).
  `arch-check` runs `scripts/arch-check.sh`: fails if `cargo tree -p yamt-gitio -e normal`
  mentions `yamt-merge-core`, or if `cargo tree -p yamt-merge-core -e normal` mentions `serde_json`,
  `tokio`, `tauri`.

## Change
1. `rust-toolchain.toml`, workspace `Cargo.toml` with `[workspace.lints]`, `[workspace.dependencies]`
   (`thiserror`, `serde`, `specta`, `specta-typescript`, `imara-diff`, `insta`, `proptest`,
   `tracing` — declared, not necessarily used yet), `clippy.toml`, `deny.toml`, `.cargo/config.toml`

   `main.rs` printing `yamt-cli: no commands yet` and exiting 0; `yamt-app` has `main.rs` doing the
   same and `bin/export-bindings.rs` as per Contract.
3. `justfile` and `scripts/arch-check.sh`.
4. Run `just check` once. Everything must be green with the frontend recipes skipped.

## Acceptance
- `just check` exits 0 (paste the recipe-by-recipe output lines).
- `just bindings` writes `frontend/src/ipc/bindings.ts`; `just bindings-check` exits 0 right after;
  editing the file by hand and re-running `bindings-check` exits non-zero (then restore it).
- `scripts/arch-check.sh` exits non-zero when a `merge-core` dep is temporarily added to `gitio`
  (prove it, then remove).
- `cargo tree --workspace -e normal --depth 1` output pasted.
