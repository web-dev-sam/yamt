## Contract (fixed; you may add, never change)

```ts
// ipc/ReviewSource.ts gains
setThreadSession(thread: ThreadId, session: AgentSessionId): Promise<SourceResult<ThreadList>>;
addAiAnswer(thread: ThreadId, session: AgentSessionId): Promise<SourceResult<ThreadList>>;
// ui/rangeAi.ts — the one owner of the threads' AI state (never in a component)
export type ThreadAi = { running: TurnView | null; end: TurnEnd | null; loaded: ConversationLoad | null };
export type RangeAi = {
  readonly byThread: Readonly<ShallowRef<ReadonlyMap<ThreadId, ThreadAi>>>;
  ask(thread: ThreadId): void;     // the prompt rule below; disabled (no-op) while this thread's turn runs
  stop(thread: ThreadId): void;
  load(thread: ThreadId): void;    // when the thread is shown open (#115), once per session
  canAsk(thread: ThreadId): boolean; // not running and at least one note since the last AI answer (or a new session)
};
export function createRangeAi(client: AgentClient, threads: RangeThreads, place: …, report: …): RangeAi;
// rangeStore gains `ai: RangeAi | null` — null without --ai; main.ts alone builds AgentSource + AgentClient (fence)
```

The prompt rule (request C2, #115): the text is every note of the thread written after its last AI answer of the
current session, in order, joined by a blank line; the first turn of a session (no stored session, or omp no longer
has it: `sessionGone`) goes out through `firstMessage(template, values)` with `RELATIVE_FILE_PATH_WITH_LINE` from
`threadPlaceText`, `MESSAGE` = that text (after `sessionGone`: every note of the thread), `RANGE` as typed,
`OLD_COMMIT`/`NEW_COMMIT` the compared ids; the template is the settings' `agent.firstMessage` or the default.
Bookkeeping (#121): `events.session` → `setThreadSession` at once; a `finished` or `stopped` end → `addAiAnswer`; a
crashed end → as measured (below). Post on an AI answer queues its `TurnView.answer` through `threads.queue`
unchanged; its Post is disabled while that answer is not loaded.
