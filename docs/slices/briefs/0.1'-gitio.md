# Slice 0.1' — gitio: unmerged stages, blob reader, stage restore, checkout -m, add

The git layer (plan §4 "Git access — subprocess only", architecture §3.2). Shells out to the
user's own git with explicit argv; bytes in, bytes out. `session` (0.2) builds open / finish /
reset on these primitives, so every primitive here is proven against git's own index.

## Target

Owned: `crates/gitio/**`

Read-only: `docs/**`, `.omp/**`, `Cargo.toml`, `Cargo.lock`, `clippy.toml`, `deny.toml`.

Dependencies already added and locked by the orchestrator: `thiserror`, `tracing`; dev:
`tempfile`. Nothing else may be added; if you need another crate, stop and say so in
`deviations_from_brief` (Cargo.lock is shared, SP6). Never depend on `yamt-merge-core`
(`just arch-check`).

Non-goals: decoding text, EOL handling, binary detection (all `session`), grouping entries per
file (`session`), `git rm` / `checkout --ours/--theirs` (v0.1), any diff logic, Windows.

## Contract (fixed; you may add private items, never change these)

```rust
// crates/gitio/src/lib.rs re-exports exactly these public items (RS10)
pub struct Repo { /* private: root: PathBuf, git: PathBuf */ }
pub struct Oid(/* private: String */);          // 40 or 64 lowercase hex chars
impl Oid { pub fn parse(hex: &str) -> Result<Oid>; pub fn as_str(&self) -> &str; }
pub enum Stage { Base, Local, Remote }            // index stages 1, 2, 3
pub struct StageEntry {
    pub mode: u32,        // parsed from git's octal, e.g. 0o100644
    pub oid: Oid,
    pub stage: Stage,
    pub path: PathBuf,    // relative to the repo root, raw bytes from git (no quoting)
}
impl Repo {
    pub fn discover(cwd: &Path) -> Result<Repo>;                         // rev-parse --show-toplevel
    pub fn root(&self) -> &Path;
    pub fn unmerged(&self) -> Result<Vec<StageEntry>>;                   // ls-files -u -z, in git's order
    pub fn blob_reader(&self) -> Result<BlobReader>;                     // cat-file --batch, long-lived
    pub fn restore_stages(&self, entries: &[StageEntry]) -> Result<()>;  // update-index -z --index-info
    pub fn checkout_merge(&self, path: &Path) -> Result<()>;             // checkout -m -- <path>
    pub fn add(&self, path: &Path) -> Result<()>;                        // add -- <path>
}
pub struct BlobReader { /* private */ }
impl BlobReader { pub fn read(&mut self, oid: &Oid) -> Result<Vec<u8>>; }

#[derive(Debug, thiserror::Error)]
pub enum Error {
    GitNotFound,
    GitFailed { args: Vec<String>, status: Option<i32>, stderr: String },
    Timeout { args: Vec<String>, after: std::time::Duration },
    BlobMissing { oid: Oid },
    UnexpectedOutput { command: &'static str, output: String },
    Io(#[from] std::io::Error),
}
pub type Result<T> = std::result::Result<T, Error>;
```

`Stage` is an enum, not the `u8` in architecture §3.2: a stage 0 or 4 cannot be built
(vision 4; the architecture doc is updated to match). `Oid`, `Stage`, `StageEntry`: `Clone,
Debug, PartialEq, Eq` (`Stage` also `Copy`). Paths come from git as raw bytes; build them with
`std::os::unix::ffi::OsStrExt` (targets are Linux and macOS only). Error messages: lowercase,
no trailing punctuation (RS7); `args`/`stderr` lossily converted for display.

## Change

1. **Running git** (RS14, RS15, RK15), one private function every call goes through:
   - `git` resolved once in `discover` by searching `PATH` with std only; absent → `GitNotFound`.
   - Explicit argv, never a shell. Always `-c core.quotepath=false`, env `LC_ALL=C`, cwd = repo
     root (`discover`: the given `cwd`). Read-only calls (`rev-parse`, `ls-files`, `cat-file`)
     also set `GIT_OPTIONAL_LOCKS=0`. stdin null unless the call writes to it.
   - Non-zero exit → `GitFailed` with argv, exit status and captured stderr.
   - One-shot calls time out after a module `const` (e.g. 30 s), std only: read stdout/stderr on
     their own threads (no pipe deadlock), poll `try_wait` until the deadline, then kill and
     reap → `Timeout`. Every call logs its argv at `debug` via `tracing`.
2. **`discover`**: `rev-parse --show-toplevel`; strip the one trailing `\n`; root as raw bytes.
3. **`unmerged`**: parse `ls-files -u -z` records `<mode> SP <oid> SP <stage> TAB <path> NUL`;
   anything else → `UnexpectedOutput`.
4. **`BlobReader`**: one `cat-file --batch` child for its lifetime. `read` writes `<oid>\n`,
   parses `<oid> blob <size>\n`, reads exactly `size` bytes plus the trailing `\n`. `<oid>
   missing` → `BlobMissing`, and the reader stays usable. Any type other than `blob` →
   `UnexpectedOutput`. Dropping the reader closes stdin and waits for the child (no zombie).
5. **`restore_stages`**: for each distinct path, first a removal record (mode `0`, all-zero oid
   of the same length as the entries' oids, the path), then that path's stage records, all
   `-z` terminated, on stdin of `update-index -z --index-info`. This is git's documented way to
   put higher stages back after `git add` collapsed them to stage 0 (RK1).
6. **`checkout_merge`**, **`add`**: `checkout -m -- <path>`, `add -- <path>`.
7. **Integration tests** in `crates/gitio/tests/` against real repos in a `tempfile` dir (RS11).
   One self-contained fixture file (e.g. `tests/fixtures/mod.rs` → `conflict_repo(…)`) that
   builds a repo, commits base on `main`, commits local and remote on two branches and runs
   `git merge` to produce the conflict. Keep it free of test-only shortcuts in `src/`: session
   (0.2) will lift it later. Fixture git calls isolate the user's config: env
   `GIT_CONFIG_GLOBAL=/dev/null`, `GIT_CONFIG_NOSYSTEM=1`, and `-c user.name=… -c user.email=…
   -c init.defaultBranch=main -c commit.gpgsign=false -c core.autocrlf=false`; also write
   `core.autocrlf=false` into the repo config so `Repo`'s own calls see it.
   Tests, each named by behaviour, oracle = git's own index / `git hash-object`:
   1. modify/modify: `unmerged()` = three entries for the path, stages `Base, Local, Remote`,
      each oid equal to `git hash-object` of that side's text, mode `0o100644`.
   2. add/add: only `Local` and `Remote` for the path (RK2).
   3. delete/modify: `Base` plus exactly one side.
   4. CRLF + no final newline: `BlobReader::read` returns each stage byte-for-byte incl. `\r\n` (RK5).
   5. one reader serves many reads in a row; a missing oid → `BlobMissing`, the next read works.
   6. reset primitive: capture `unmerged()`, `add(path)` → path gone from `unmerged()`,
      `restore_stages(captured)` → `unmerged()` equal to the capture; same for add/add (RK1).
   7. after step 6, `checkout_merge(path)` → the worktree file contains `<<<<<<<` (RK17).
   8. a failing git call (e.g. `checkout_merge` on a path with no stages) → `GitFailed` with
      non-empty `stderr` and the argv (RK15).
   9. `discover` from a subdirectory returns the top level; outside any repo → `GitFailed`.
   10. a conflicted path with a space and a non-ASCII character round-trips through
       `unmerged()` → `restore_stages` unchanged (`-z` + `quotepath=false`).
   11. timeout (unit test in-file, private function with a short timeout): a git call that never
       finishes (e.g. a `!sleep` alias passed via `-c alias.…`) → `Timeout`, child reaped.
