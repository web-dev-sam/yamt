## Findings to fix (quoted, with the decision)

- #325 (boundary, should): "When take's worktree write fails, it restores the stages captured at
  open() and sets Unresolved even for a file that was already Resolved. A failed retry therefore
  undoes the earlier resolution …" **Decision:** a failed `take` puts back the index and the status
  exactly as they were before the call: an `Unresolved` file gets its captured stages back (as now);
  a `Resolved` file gets back the stage-0 entry it had before the call (read it before staging — a
  new read-only `gitio::Repo` method over `ls-files -s -z -- <path>` with an integration test is
  fine) and stays `Resolved`. Test both.
- #331 (correctness, should): "If restore_stages fails after the worktree write failed, the `?`
  returns the restore error and drops the write error. Status keeps its old value … while the index
  already holds the chosen side's stage-0 entry." **Decision:** return the original error; record
  the restore failure with `tracing::warn!` (target `session`, event and path as fields); set the
  status from what the index then holds (the chosen side's stage 0 still in place → `Resolved`), so
  the file list never disagrees with git.
- #332 (correctness, should): "When `git add` fails and writing the old bytes back also fails, `?`
  returns WriteFailed and the Git error that caused the rollback … is lost." **Decision:** return the
  Git error; record the rollback failure with `tracing::warn!` as above. No new error variant.
- #333 (correctness, should): the submodule test passes even with the `SUBMODULE_MODE` arm deleted.
  **Decision:** remove the submodule's directory before `take` and assert it is still absent
  afterwards (or a marker file inside survives — say which).
- #334 (correctness, should): the file-vs-link take test passes even if `take` writes nothing.
  **Decision:** delete both worktree paths before the takes, then assert the link and the file.
- #327 (boundary, should): `remove_worktree_file`'s match in the same shape as `worktree_bytes`
  (Ok / Err NotFound / Err other).
- #328 (boundary, should): split `merged_worktree` into a guard named for what it asserts
  (`require_conflict_markers`) and a plain read.
- nits riding along: #329 move `describe_blob` into `sides.rs` so only `sides` depends on `decode`;
  #330 use `REGULAR_FILE_MODE` in the expected index line; #335 `checkout-index -u --force` so the
  stage-0 entry gets fresh stat data (prove with `git diff-files --quiet -- <path>` exiting 0 after a
  take in one test).
