## Change

1. `args.rs`: `--diff=<text>` → `RangeSpec::parse`; `--repo <p>` in either order; `--diff` alone stays `Compare`
   (`--diff --repo` stays `DIFF_WITH_REPO`); every usage line of the design's §1 table (incl. "give --diff or one
   --diff=<range>, not both" for `--diff` with `--diff=` and for a second `--diff=`); the help text of §1 verbatim.
2. `lib.rs`: the `Range` arm (`appimage::repo_from_start_dir` on Linux, then `range::run_range(&repo, &spec).report()`).
3. `range.rs`: `run_range` — `Resolved::resolve` (an error → `Ending::failure`, exit 2, no window), build the app with
   `commands::with_range(builder)`, `PairLock::take(<data_dir>/yamt/range, …)` (refused → `Ending::failure`), `list`,
   manage `RangeState`, open with title `"<range as typed> — <repository folder name> — yamt"` and
   `WindowKind::Range`, exit 0 at close with no question. No `MergeSession`, no `servers::manage`, no `TabStore`.
   `load_range_file` runs `Range::load` on the worker.
4. `commands.rs`: register `open_range`, `load_range_file`; `with_range(builder)`.

## Acceptance

Tests (each naming its bug): `args.rs` — each usage line; `--diff=a..b --repo p` in both orders; `--diff` alone stays
`Compare`; the help names `--diff=<range>`. `range.rs` — `open_range` equals `Range::start`; an unknown id answers
`UnknownRangeFile`; the title format. `window.rs` — the start script carries `data-window="range"`. Real app (`just

a different pair opens beside it; closing exits 0. (The window shows the merge page until row 9 lands; say what you
