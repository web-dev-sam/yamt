## Behaviour

1. **Mark** (`FileMark.vue`, used by the list and the tree for every status): a `Remembered` file shows Lucide
   `history` with the word "remembered" muted beside the name, hover/accessible name "git rerere filled in a resolution
   you recorded before; review it, then Mark resolved"; `Resolved` and `Unresolved` look as today.
2. **Counts.** The summary counts a conflict whose `waiting` is `Remembered` and still waiting on both sides as
   `remembered`, not as a `conflict` (`MergeSummary` gains `remembered`); once a side is applied or ignored it counts as
   any decided conflict. The toolbar label adds "1 remembered" (`summaryLabel`).
3. **Mark resolved** never asks "Unprocessed Changes" for remembered conflicts: `finishMustAsk` ignores `remembered`;
   other waiting changes still ask as today; the question's words do not mention remembered ones.
