## Blocks

1. **#1580** (both reviews): `OperationLabel.vue:13-14` — both `useElementBounding` calls keep vueuse 15's default
   capture-phase window `scroll` listener (`windowScroll: true`), so every scroll in any pane or the file list calls
   `getBoundingClientRect` on the tag and its word, though the tag never moves on a scroll (it sits in no scroller,
   `body` is `overflow: hidden`). Plan §2 #51 tuned that scroll path for WebKitGTK. Fix: `{ windowScroll: false }` on
   both; `show()` already re-measures, the `ResizeObserver` (the hide) and the window `resize` listener stay.
2. **#1581** (boundary): the tooltip is a `fixed` sibling of the tag inside the file list's `<aside>` (no Teleport,
   accepted in round 1). It is placed and layered right only while the `<aside>`, its ancestors and the pane hosts create
   no containing block or stacking context (no transform, `will-change`, filter, `contain`, `content-visibility`,
   `isolation`, positioned z-index). Fix: `ui/AGENTS.md` states this condition and that adding such a property there
   moves the tooltip to a `body` Teleport.
3. **#1582** (boundary, vision 2): the tooltip look lives twice — `editor/theme.css:279-291` (problem and removal
   tooltips: 1 px `--color-control-border` border, 4 px radius, `--color-panel` background; the problem tooltip also
   `--color-fg`, `--font-sans`, 13 px) and the tag tooltip's class list (`OperationLabel.vue:70`). Fix: one place holds
   that look — a Tailwind `@utility` in `style.css` (e.g. `hover-tooltip` for the surface; the problem tooltip's text
   look with it or as a second one) — used by the tag tooltip's classes and by `theme.css`'s rules (Tailwind 4:
   `@reference "../style.css";` then `@apply`; `@tailwindcss/vite` 4.3.3 is in `vite.config.ts:25`, which vitest uses
   too). Changing it there changes all three tooltips. The 480 px of `operationTooltip.ts` stays #100's own number.
   If Tailwind cannot serve `theme.css` this way, say why in `deviations_from_brief` with the error, and propose the
   nearest single source; do not fall back silently.
   `editor/AGENTS.md`'s removal-tooltip paragraph and `ui/AGENTS.md` name where the look lives.
