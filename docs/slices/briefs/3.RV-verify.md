## Recipes

1. `just check` from the main checkout at HEAD (incl. `map-check`, `bindings-check`, `fixtures-check`, `arch-check`,
   `sfc-order`, `web-unused`, `hooks-test`). Any failure is `gate: fail` with its first 30 relevant lines.
2. No mutation run (owner #1630, VF7): every patch was mutated on its own during review; the records are
   `.omp/run/mutants/RV*.survivors.txt`, triaged in `.omp/run/findings.jsonl`. Do not run `just mutants`.
3. `pnpm -C frontend test:browser`: attempt once; if Playwright WebKit cannot launch (`libicudata.so.74`, #1445), run
   `src/editor/range.browser.test.ts` and `src/editor/rangeThreads.browser.test.ts` through a private Playwright WebKit
   under `/tmp/yamt-pw` as earlier verifier runs did, and say so. None of these files has run before this feature.
4. WebKit, fixture page (`just app-session start-fixture --range-case review [--threads seeded] [--gitlab <script>]
   [--ai [--ai-case <case>] [--ai-changes]]`, 1600×1000), dark **and** light:
   a. **A:** the file list as GitLab lists it (marks, `+n −m`, renamed "old → new", binary/too-large/submodule rows
   named), list and tree; two read-only columns with bands and word marks; an added file's empty left, a deleted
   file's empty right; Ctrl/Cmd+B; `?range=empty` → "No changes".
   b. **B:** hover a line number → the comment button; a press opens a box; Ctrl/Cmd+Enter adds the thread; the line's
   mark and the file row's count; collapse/reopen; reply; Post → edit → Queue → "Send to GitLab (1)"; Unqueue; Send
   with `--gitlab lined-up` → "Pending on GitLab" with the link and Copy; `--gitlab refusal` → one refused with its
   reason, the rest sent; a not-lined-up script (`moved`, `noGlab`, `loggedOut`) → both buttons disabled with its
   sentence while Unqueue works; typing in a box never reaches the columns (arrows, Ctrl+A/C, Ctrl+F).
   c. **C:** without `--ai` no Ask AI and no AI settings section; with `--ai`: Ask AI → live "Thinking and steps" →
   the answer (Markdown, a code block coloured); an edit opens as a diff; Stop → "You stopped the AI."; `--ai-case
   crash` → the failure sentence with Retry, Retry continues; Post on a loaded answer queues its text; Settings → AI
   (Agent command, First message, the placeholders).
5. Real app on a private X display (`cargo tauri build --debug --no-bundle`; repository from `scripts/range-repo.sh
   /tmp/yamt-rv/verify/repo`; record yamt's exit status with a wrapper as earlier runs did):
   a. `yamt --diff=main...feature` in the repository: the window opens on the merge base vs `feature`; `main..feature`
   too; a second window on the same pair exits 2 naming the open one; a bad range exits 2 with git's words; `git
   status --porcelain=v2` and the refs are the same before and after.
   b. `--glab lined-up` (`just app-session start-app --range … --glab lined-up`): add two threads, Post both, Send →
   the fake's log has two POSTs with the three SHAs and positions; close; reopen → threads back, "Pending on GitLab".
   `--glab refusal`, `--glab moved`: as the fixture page.
   c. `--ai` with real `omp acp` (installed): Ask AI on a thread → steps and the answer; `threads.json` holds the session
   and `aiAnswer` turn 0; Stop a second turn; ask the AI to edit a file; close (a real WM_DELETE_WINDOW) → "Keep the
   AI's changes?" with Keep focused, Escape stays; Keep → exit 0 and the checkout stays; reopen → the conversation
   loads; reload the page mid-turn → no `omp acp` process left, the checkout stays, the next answer shows its own turn;
   close → Discard → the checkout folder is gone.
   d. With `GIT_DIR=<repo>/.git` exported, an `--ai` window's Ask AI leaves the repository's branches, remote and HEAD
   unchanged.
