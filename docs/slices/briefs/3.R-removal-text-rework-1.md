   every test. In that case the tooltip would show only part of the removed code. The weaker property here ('the first
   or last k parts are k consecutive whole base lines') also passes when lines are dropped or when an extra paired line

   catalogue case has one removed line. The stress test has no truth for `DeleteLine`."

   chunk side's end (rule 3), and joined with a pair's leading or trailing tokens — e.g.

   traced by the reviewer; pin what the rules give and say if it differs). And a generated check that a text made only
   of whole lines has exactly as many `\n` as there are unpaired base lines between its neighbouring pairs — e.g. a
   `word_stress` `Truth` for a `DeleteLine` run whose removal text holds every deleted line, in order.
