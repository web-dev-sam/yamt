## Behaviour

1. **Header** (`ServerStatus.vue`): counts and note as today; then the pinned servers' buttons (today's look and menu,
   in view order); then `ServerGroup`. Rendered only while there are views, as today.
2. **Group button**: a dot (`groupDot` over every view's `dotKind`), the word "Servers", lucide `chevron-down`; title and
   accessible name "Language servers"; `aria-haspopup="menu"`, `aria-expanded` while its list or a row's menu is open.
3. **Drop-down**: teleported to the body, placed by `menuPosition` at the button's bottom-left like `ServerMenu`,
   `max-h-[60vh] overflow-y-auto`, `role="menu"` labelled "Language servers"; per server a `role="none"` row with a
   `menuitem` (dot, name, title = the state line, `aria-haspopup="menu"`) and a `menuitemcheckbox` pin (lucide `pin`,
   `aria-checked`, a pressed look while pinned, titles "Pin to the header" / "Unpin from the header", accessible name
   "Pin <name> to the header"). Up/Down step through row 1, pin 1, row 2, … (`stepMenuItem` over `MENU_ITEMS`); a pin
   toggles at once and the list stays open with the keyboard on it; choosing a row closes the list (keyboard back to the
   group button) and opens that server's `ServerMenu` at the same place with the group button as opener; a click on the
   group button while a row's menu is open only closes that menu.
4. **`ServerMenu`**: its Escape/Tab step focuses `opener` before `close` (pinned buttons too).
5. **`useDropdownMenu`**: also closes on window blur (every drop-down: `PresetPicker`, `KeymapList`, the group);
   `menuKeys` queries `MENU_ITEMS`.
6. **Fixture page**: `?servers` in the URL builds a fixture host (`ipc/fixtureServers.ts`): one root project under
   fixture mode's repository root with `package.json`, `tsconfig.json`, TypeScript 5.9.3, `.bin/oxlint`,
   `.bin/typescript-language-server`, an eslint config and package; `findProgram` walks `.bin`; `projectFiles` answers
   the tree; a start answers `SpawnFailed` with "language servers run only in the app". Without `?servers` nothing
   changes.
