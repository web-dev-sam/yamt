## Behaviour

1. **Local** (stage 2 = HEAD), read once in `MergeSession::open`:
   - HEAD on a branch → `SideName::Branch { name }`, the short name `git symbolic-ref --quiet --short HEAD` prints
     (`local`, `feature/x`; also for a branch with no commit yet).
   - HEAD detached (a rebase, a merge on a detached checkout) → `SideName::Commit` of HEAD's commit, exactly the
     form the right side uses: `%h`, `%s`, `%B` trimmed — reuse the existing `commit_name`.
   - neither (no commit and no branch) → `None`.
     Checked here: `git symbolic-ref --quiet --short HEAD` prints `feat/x`, exit 0, on a branch; prints nothing,
     exit 1, after `git checkout --detach` (git 2.56.0) — the same "not found" shape `commit_named` already maps to
     `None` (`is_unresolved_name` in `repo.rs`).
2. **Remote**: today's `merged_in` result, unchanged (#50).
3. Each side is read on its own: a git failure while reading one side's name leaves that side `None`, logs a `warn`
   naming the side (one event name for both, e.g. `side_name_unread` with a `side` field), and never touches the
   other side's name or stops the app starting.

```rust
// crates/session/src/side_names.rs, re-exported from lib.rs
/// What one side of the merge is: a branch, else a commit.
#[derive(Clone, Debug, PartialEq, Eq, Serialize, Type)]
#[serde(tag = "kind")]
pub enum SideName {
    Branch { name: String },
    Commit { short_id: String, subject: String, message: String },
}

/// Both sides' names, read once when the session opens; `None` when nothing names that side.
#[derive(Clone, Debug, PartialEq, Eq, Serialize, Type)]
pub struct SideNames {
    pub local: Option<SideName>,
    pub remote: Option<SideName>,
}

pub(crate) fn read_side_names(repo: &Repo) -> SideNames;

impl MergeSession {
    pub fn side_names(&self) -> &SideNames;   // the field `side_names` replaces `remote_name`
}

// crates/gitio/src/repo.rs
impl Repo {
    /// The branch HEAD is on (`symbolic-ref --short`); `None` when HEAD is detached.
    pub fn current_branch(&self) -> Result<Option<Vec<u8>>>;
}

// src-tauri/src/commands.rs — registered in the one tauri-specta builder in place of `remote_name`
#[tauri::command]
#[specta::specta]
fn side_names(state: State<'_, SessionState>) -> SideNames;   // lock, clone, return
```
