# Keyboard shortcuts

Shortcuts work anywhere on the board except while typing in a text field.

## Cards

| Key     | Action                              |
| ------- | ----------------------------------- |
| `N`     | New card in the focused column      |
| `E`     | Edit the focused card               |
| `A`     | Archive the focused card            |
| `L`     | Add a label to the focused card     |
| `M`     | Assign the focused card to yourself |
| `Enter` | Open the focused card               |

## Moving around

| Key        | Action                                  |
| ---------- | --------------------------------------- |
| `←` `→`    | Focus the previous or next column       |
| `↑` `↓`    | Focus the previous or next card         |
| `Shift+←→` | Move the focused card to another column |
| `/`        | Search cards                            |
| `?`        | Show this list                          |
