Owner skills: `skill://ts-conventions`, `skill://ipc-contract`. `bindings.ts` is generated — never edit. `domain.ts` is the only place brands are created (the compare window's guards and `nextColumnVersion` included); `fixture.ts` is the only file allowed `as` (after valibot); `log.ts` is the only file allowed `console.*`. The compare window (`yamt --raw`, plan §2 #93–#97) has its own `CompareSource` (`CompareSource.ts`): domain shapes and their conversions in `compareDomain.ts`, the app's in `tauriCompare.ts`, fixture mode's in memory in `fixtureCompare.ts` (`?raw=<case>` loads `fixtures/compare/<case>.json` into tab 1; the tab rules mirror `crates/compare`).

`tauri.ts` `readClipboard(selection)` is the window's one way to read the clipboard (plan §2 #99): the shell's GTK text request, `null` for unreadable or no text; only `ui/linuxPaste.ts` calls it, on Linux. `keys.ts` holds both platform tests: `isMac` (CodeMirror's `Mod`) and `isLinux` (the one Linux rule, also behind `showsAntialiasing`).
