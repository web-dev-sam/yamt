## Summary

- `gitio::Repo::current_branch() -> Result<Option<Vec<u8>>>`: `git symbolic-ref --quiet --short HEAD`; detached →
  `None` (exit 1, empty stderr, `is_unresolved_name`); git failure → `Err`.
- `session/src/side_names.rs` (replaces `remote_name.rs`): `SideName` (`Branch { name }` | `Commit { short_id,
  subject, message }`, tag `kind`), `SideNames { local, remote }`, `read_side_names(repo)`: local = HEAD's branch,
  else HEAD's commit (`commit_name`), else `None`; remote = `merged_in` unchanged. Per side: a git failure → that side
  `None` + `warn` `side_name_unread` with `?side` (the `Side` enum).
- `MergeSession::side_names() -> &SideNames` (field `side_names`) replaces `remote_name()`; command `side_names() ->
  SideNames` replaces `remote_name`.
- Bindings regenerated by the orchestrator: `commands.sideNames(): Promise<SideNames>`, types `SideName`, `SideNames`.

## Tests

- gitio `merge_heads.rs`: branch short name (`local`, `feature/x` via `symbolic-ref HEAD` because checkout cannot run
  mid-merge), unborn branch → its name, detached → `None`, outside a repository → `GitFailed`.
- session `tests/side_names.rs` (replaces `remote_name.rs`): every case asserts both sides; new: merge from a detached
  checkout (local commit form), rebase (local = commit form of `remote`'s tip although branch `remote` points at it),
  unreadable `MERGE_MSG` drops only remote, a symbolic-ref loop at HEAD (`fatal: No such ref: HEAD`, asserted) drops
  only local.
- src-tauri: `side_names_names_both_branches_of_the_merge` → `{"local":{"kind":"Branch","name":"local"},
  "remote":{"kind":"Branch","name":"remote"}}`.
