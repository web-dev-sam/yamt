# Risk register

Source: `docs/plan.md` §6 + architecture §3.3. A reviewer uses the last column as the
checklist: if the slice touches the owner, the proving test must exist or be named in
`open_risks`.

| id   | risk                                                                                                                   | owner                                                                                                                                   | proving test                                                                                                                                                                                                                                                                                         |
| ---- | ---------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| RK1  | `git add` collapses stages 1/2/3; reset impossible unless SHAs captured at load                                        | `session::MergeSession::open` captures `stages`; `reset` replays via `update-index --index-info` then `checkout -m`                     | `session/tests`: finish, then `git update-index --clear-resolve-undo`, then reset ⇒ `ls-files -u` identical to before finish (without the clear, `checkout -m` rebuilds from resolve-undo and lazy capture passes)                                                                                   |
| RK2  | add/add has no stage 1 ⇒ `stages[0]` lookup panics                                                                     | `session`: `base = Some("")`                                                                                                            | `merge-core` proptest: `base == ""` ⇒ one chunk, `Conflict` unless `local == remote`; `gitio/tests`: add/add repo fixture                                                                                                                                                                            |
| RK3  | delete/modify: one side missing                                                                                        | `session`: `UnsupportedReason::{LocalDeleted, RemoteDeleted}`                                                                           | `session/tests`: open lists it with its reason; reset of a delete/modify resolved outside restores its stages                                                                                                                                                                                        |
| RK4  | "locked scrolling" ≠ shared `scrollTop`; naive sync drifts                                                             | `editor/internal/scrollSync.ts` piecewise-linear through chunk anchors                                                                  | `scrollSync.test.ts`: drift ≤ 1 line at every anchor on a 2k-line fixture                                                                                                                                                                                                                            |
| RK5  | CRLF files silently rewritten to LF                                                                                    | `session` detects `Eol`; `editor` sets `lineSeparator`; `resultText()` uses `sliceDoc()`                                                | `session/tests`: CRLF round-trip bytes identical; `pane.test.ts`: CRLF result contains `\r\n`                                                                                                                                                                                                        |
| RK6  | binary / non-UTF-8 blob reaches the webview                                                                            | `session`: NUL in the first 8000 bytes (git `FIRST_FEW_BYTES`), size, or `from_utf8` failure ⇒ `unsupported`                            | `session/tests` + `decode.rs` tests: `Binary`/`TooLarge`/`NonUtf8`, incl. sides failing differently                                                                                                                                                                                                  |
| RK7  | chunk grouping gap is a tuning parameter with no correct value                                                         | `merge_core::DEFAULT_GAP`, goldens                                                                                                      | `just golden` + owner compares the 10 goldens against WebStorm in the window (M1 wave 3; deferred Gate C)                                                                                                                                                                                            |
| RK8  | Arch + NVIDIA blank webview (DMABUF)                                                                                   | `src-tauri/src/main.rs` env guard before builder                                                                                        | M3 manual; `main.rs` unit test: guard respects a preset value                                                                                                                                                                                                                                        |
| RK9  | three-pane connector geometry has no reference implementation                                                          | `connectors/` pure geometry                                                                                                             | `connectors/*.test.ts`: snapshot of band paths for fixture; chunk above/below/spanning viewport                                                                                                                                                                                                      |
| RK10 | chunk ranges drift after user edits in the center pane                                                                 | `editor/internal/chunkField.ts` maps via `tr.changes.mapPos`                                                                            | `chunkField.test.ts`: insert before chunk ⇒ range shifts; insert inside ⇒ range grows; delete all ⇒ dismissed                                                                                                                                                                                        |
| RK11 | undo reverts text but not chunk status                                                                                 | `chunkField` effect with `invertedEffects`                                                                                              | `chunkField.test.ts`: apply → undo ⇒ status `pending`                                                                                                                                                                                                                                                |
| RK12 | bulk apply yields N undo steps                                                                                         | `apply.ts` builds one `state.changes([...])`                                                                                            | `apply.test.ts`: bulk then one undo ⇒ original text                                                                                                                                                                                                                                                  |
| RK13 | `merge-core` chunks disagree with git's own merge                                                                      | `merge_core::apply_non_conflicting`                                                                                                     | `cli/tests/merge_file.rs`: when yamt and `git merge-file -p --diff-algorithm=histogram` are both conflict-free, outputs are byte-equal; both-clean ≥ 25% of 512; yamt-clean/git-conflict ≤ 1% (`MAX_ONLY_GIT_CONFLICT_PERCENT`, the dangerous direction)                                             |
| RK14 | chunks overlap or are unsorted                                                                                         | `merge_core::compute_chunks` sweep                                                                                                      | proptest: sorted, pairwise disjoint in all three spaces                                                                                                                                                                                                                                              |
| RK15 | git subprocess hangs or inherits a shell                                                                               | `gitio`: explicit argv, `LC_ALL=C`, timeout covering exit and output pipes, stderr captured                                             | `gitio/tests`: failing command ⇒ `Error::GitFailed { stderr }`; `run.rs`: hanging call and a child holding stderr open ⇒ `Error::Timeout`                                                                                                                                                            |
| RK16 | a mixed-EOL file is normalised                                                                                         | `session`: `Eol::Mixed` passes bytes through, UI banner                                                                                 | `session/tests`: mixed fixture round-trips byte-identical                                                                                                                                                                                                                                            |
| RK17 | reset of a file after the app wrote the worktree leaves the worktree without markers                                   | `session::reset` runs `git checkout -m -- <path>` after stage restore, skipped for one-sided files and gitlinks (`can_rebuild_markers`) | `session/tests`: worktree contains `<<<<<<<` after reset                                                                                                                                                                                                                                             |
| RK18 | non-regular file (symlink 120000, gitlink 160000) breaks the whole merge or is written back as a regular file          | `session`: mode-based `Symlink`/`Submodule` before any blob read; reset skips `checkout -m` for gitlinks                                | `session/tests`: `submodule_and_symlink_conflicts_are_unsupported_and_the_text_file_still_loads`, `reset_of_a_submodule_conflict_keeps_its_stages_and_leaves_it_unresolved`; OPEN: reset of a symlink resolved outside the app rewrites the link as marker text (#86), decide with take-local/remote |
| RK19 | user git environment (XDG attributes/ignore, env-passed config) leaks into test repos ⇒ tests pass or fail per machine | `conflict-repo::isolated_git`, `scripts/golden-repo.sh` `repo_git`                                                                      | conflict-repo: hostile-`XDG_CONFIG_HOME` unit test (slice scheduled); script: 0.3′ rework-1 hostile-XDG acceptance                                                                                                                                                                                   |
