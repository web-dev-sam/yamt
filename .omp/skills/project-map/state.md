# yamt — project map: state ownership (vision 2)

One owner per piece of state; only the owner writes it (`skill://review-protocol` growth check; the full text is
`docs/architecture.md` §5.1). Read by row: `grep -n '<state or file>' .omp/skills/project-map/state.md`.
