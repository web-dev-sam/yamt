Owner skill: `skill://rust-conventions`. The compare window's stored tabs (plan §2 #93, #95, #97): `lib.rs` (the IPC types `TabId`, `Column`, `ColumnVersion(s)`, `TabLanguage`, `TabEntry`, `TabList`, `CompareStart`, `Comparison`, `TabTexts`; `MAX_COLUMN_BYTES` 8 MiB, the merge window's per-file limit; `Error`; `LoadedTab` — a tab's two texts as `Arc<str>` plus their versions, cloned out of the store so `comparison`/`tab_texts` run `yamt_merge_core::compare` after the caller released the store's lock), `store.rs` (`TabStore`: open, start, load_tab, set_column, add/close/rename/set_language/show; versions in memory only, 0 per tab at open; `tabs.json` written only when it changed, a failed write changes nothing in memory), `index.rs` (`tabs.json` format 1: `format`, `shown`, `nextId`, `tabs` [`id`, `number`, `name`, `language`]; refused as `Broken` when it does not parse, has no tabs, repeats an id, holds an id not below `nextId`, or shows a tab it does not list; `NewerFormat` above 1; the tab rules: number 1 + the highest, ids from `nextId`, closing shows the next else the previous, the last closed leaves a new "Compare 1"), `files.rs` (in the data folder: `<id>-left.txt`/`<id>-right.txt` plain UTF-8, missing = empty; `lock` held with `File::try_lock` for the store's life; every write a `<name>.tmp` + rename; column and temp files of tabs not in the index removed at open, every other file left alone). A broken or newer `tabs.json` is refused before anything in the folder is written. Dependencies: `yamt-merge-core` (the one `yamt-*`, `just arch-check`), `serde`, `serde_json`, `specta`, `thiserror`; never `tauri`. Tests: `tests/opening.rs`, `tests/tabs.rs`, `tests/columns.rs` on real temp folders.
