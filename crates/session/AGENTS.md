The disk is the truth (plan §2 #52/#53): each file remembers what yamt last saw on disk (`disk.rs` `Seen`, read back after each own write); `refresh` settles every difference in `disk.rs` (no marker lines → one batched `git add` / `update-index --force-remove`; marker lines → the view becomes the disk), then re-reads `ls-files -u` (plan §2 #49); finish/take/reset first look at their file and refuse a changed one or a stale `DiskVersion` with `WriteReply::ChangedOnDisk`. `markers.rs` reads git's markers from bytes, `seed.rs` builds the middle text and one conflict per open block from the disk, `start.rs` compares each file with what git wrote at `open` (`git merge-file`, `hash-object`, attributes). `remote_name.rs` names what is merged in, read once at `open`; a git failure there only drops the name (plan §2 #50). Finish and take are all or nothing: a failed stage leaves worktree and index as they were.
