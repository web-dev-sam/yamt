The per-user settings file (plan §2 #57, #60): `lib.rs` (types crossing the IPC, `Error`, the six operations: `read`, `set_theme`, `set_antialiasing`, `set_keys`, `relocate`, `stored_at_start`), `places.rs` (`Places`: the default file, the `settings-location` file, `~/` expansion), `file.rs` (parsing into kept entries, writing through a temporary file and a rename). No tauri, no git, no `yamt-*` crate (arch-check); action ids and key strings are opaque text. Tests are integration tests on temp folders in `tests/` (`settings.rs`, `antialiasing.rs`, `relocate.rs`, helpers in `config/`), plus two unit tests in `lib.rs`: `a_theme_name_is_its_serde_spelling` and `an_antialiasing_name_is_its_serde_spelling` (`name` = the serde spelling).
